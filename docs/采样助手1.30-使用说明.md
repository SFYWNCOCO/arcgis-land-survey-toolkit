# 采样助手 1.30 使用说明（给没接触过 ArcGIS Pro 的人）

## 你会得到什么

选一次图层、点一次按钮，程序自动完成并输出：

| 成果 | 位置 | 用途 |
|---|---|---|
| 评价单元面 | `db\成果.gdb\评价单元` | 单元划分结果，含编号、面积（亩）、图斑清单 |
| 方格网 | `db\成果.gdb\方格网` | 20 m 网格（可改），裁到单元内 |
| 网格交点 | `db\成果.gdb\网格交点` | 网格节点 |
| 网格中心点 | `db\成果.gdb\网格中心点` | 网格中心 |
| 设计采样点 | `db\成果.gdb\设计采样点` | 最终布点，含样品编号（=单元编号） |
| 四套 shp | `shp\` | 直接给外业/内业用的分层文件 |
| 影像底图 | `imagery\` | 按成果范围自动拼好的 GeoTIFF |
| 逐单元图 | `map\PNG + PDF` | 每单元一张采样点位图，另有 000_总览 |
| 成果报告 | `一键成果报告.json` | 单元数、点数、间距、待人工确认清单 |

## 三步操作

1. 打开 ArcGIS Pro，把补充耕地图斑（shp 或 gdb 图层）拖进地图。
2. 点功能区 **补充耕地验收 → 一键出成果 → 采样助手**，右侧出现面板。
3. 面板里：选中图斑图层 → 参数保持默认 → 选影像来源 → 选一个新的空文件夹 → 点 **一键生成成果并出图**。

跑完点 **打开成果文件夹**，进 `map` 看逐单元图。

不需要会的操作（程序已代做）：叠加图层、生成渔网、提取交点/中心点、筛选样点、分层导出 shp、加影像、配符号、套模板、写图名图号、算面积统计、导出 PDF。

## 面板上的参数什么时候才改

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| 网格尺寸 | 20 m | 单元很小（<5 亩）或要求更密时改 10 m；面积大要求粗时可改 25–30 m |
| 每单元最低点数 | 3 | 规范下限，一般不改 |
| 点位最小间距 | 15 m | 规范"一般不小于 15 m"，一般不改 |
| 田边避让 | 5 m | 田块窄、边缘有沟渠时调大 |
| 单元面积上限 | 50 亩 | 项目另有规定才改 |
| 可合并图斑间距 | 30 m | 只在项目认定"相对集中"要合并时才调 |
| 允许多部件合并 | 否 | 勾上才允许把不共边的图斑合成一个单元（会产生多部件，须人工确认） |

## 影像底图怎么选（关键）

| 选项 | 效果 | 能不能进报件 |
|---|---|---|
| 项目自有影像 | 直接用你给的 DOM/航片，程序只核对坐标系 | 能（须自己核对时相与来源） |
| 天地图影像 | 需要天地图 key，程序按范围下载拼接 | 须按合同与审图要求确认 |
| 演示影像 | 公开 Esri World Imagery，自动下载 | **不能**，只能自查/演示 |

程序会在图面"影像来源"里写明实际用的来源；演示影像会标注"仅供自查"。

## 程序不会替你做的事

- 评价单元划分结果是**候选**：合并/拆分要在影像上人工复核（报告里 `待人工确认` 有清单）。
- 采样点是**设计点**，不是实采点：均匀性、田边避让、代表性、可达性必须现场核验。
- 判定"合格/等级"：程序不判。
- 图号、编制单位、制图人/审核人：面板里填，不填就是"（待填）"。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示"图层存在选择集/定义查询" | 地图上该图层有选中要素或筛选；清除选择、取消筛选再跑 |
| 提示"坐标系未定义" | 图斑没有 .prj；先定义坐标系（CGCS2000 3 度带，广西多为 36 带） |
| 提示"成果文件夹非空" | 换一个新的空文件夹，程序不覆盖 |
| 影像下载失败 | 断网/被墙；改用项目自有影像 |
| 出图很慢 | 影像瓦片下载占大头；单县 100 单元建议分批次跑 |
