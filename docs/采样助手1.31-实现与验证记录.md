# 采样助手 1.31 实现与验证记录

日期：2026-10-24。状态：实施中，属于候选开发版本；尚未完成整份计划的业务和移机验收。

## 本轮已实现

- 项目 DOM 支持单文件和同坐标系影像目录；多幅栅格写入拼接工作副本。可读取旁置 `.source.json` / `imagery_metadata.json` 的来源线索，未提供精度证明的项目保持待核。
- 逐图幅和逐单元保存影像清单及项目汇总；在线服务按中心/四角查询 World Imagery 元数据。服务、版本、凭证摘要分别隔离缓存。服务像元间距、输出像元和源 GSD/位置精度分开记录。
- 生成含范围 GeoJSON、缺项、坐标要求和交付清单的无人机补测需求包。未获取在线影像时可生成矢量预览，并报告影像失败。
- 侧栏按完整数据路径区分重名图层；显示总数、定义查询数和当前选择数，并明确选择本次范围。高级布点选项折叠，默认自适应网格。
- 输出地理位置图、采样点位布置图及逐单元补图的 JPG、PNG、PDF。安装模板改为包内相对路径，辅助节点/中心默认隐藏。每幅应用查询、验证数据源、读回导出文件并生成缩略图。
- 分阶段保存资料、采样、影像和制图上下文。取消在阶段边界生效；继续时复用有效阶段，重做失败阶段。源图斑、参数或影像变更会使相关下游失效。导出端支持单幅收据、损坏检测和有效文件复用。
- 接入独立采样空间质检；生成点位 CSV、预填标签 CSV 和标为“待确认”的可打印标签 HTML。采样比例尺建议不再被当作硬失败，图面像元文字不能证明正射位置精度。

## 本轮发现并修复的问题

已有单元融合使用了错误 ArcPy 命名空间；真实恢复测试发现后改为 `management.Dissolve`。目录选择器缺少 Catalog 程序集，已通过实际 C# 编译补齐。GP 的第一个输出是成果文件夹，验证脚本现读取最后一个派生成果报告。

负向工程需用 `saveACopy` 保持相对数据连接，直接复制 APRX 会破坏测试前提。图层计数改为按已应用 SQL 读取数据源，避开独立进程中的临时 GPLYR 令牌。新版图面缩短影像注记，并取消模板默认的未证实高程基准。曾尝试隐藏图形比例尺，但 Pro 3.1.5 保存后重新读取布局会崩溃；最终保持图形比例尺可见并移到面积表下方，同时保留数值比例尺。

作用域基线检查未通过：共享工作区 HEAD 在本轮期间由其他工作推进。已检查旧 HEAD 至当前 HEAD 的目标插件/规范技能路径，没有相关提交；未重建事后基线来放行。原始基线与检查输出保留在 `temp/arcgis-implementation-baseline-20261023.json`、`temp/arcgis_scope_report_20261024.json`。
