# 出图工作台实施计划

已确认目标：自动比例尺与逐幅设置、影像覆盖、固定绘制顺序、当前图/整套重绘、PDF与浏览目录。

架构：继续使用 C# 工作台 → Python Toolbox → ArcPy。比例尺进入现有项目参数和阶段失效逻辑；重绘只更新图件阶段，不重建地块、网格或采样点。

1. 在 `acceptance/sheet_plan.py` 增加逐幅比例尺覆盖，按实际图框计算范围并拒绝裁切；`workflow.py` 传入参数，`task_state.py` 使影像及下游失效。测试几何覆盖、非法尺度及单幅不影响其他图幅。
2. 在 `map_worker.py` 复用分组顺序，`map_export.py` 导出前稳定重排并读回验证；全图框影像检查保留，未知精度不得提升状态。
3. 新增 `acceptance/map_redraw.py`：独立职责是验证任务绑定、重绘现有计划、合并逐幅成果、原子发布新报告。现有 workflow 是全阶段执行器，不能承接只重绘操作的生命周期；实际入口为 `GridSampling.pyt` 新工具及工作台按钮。取消在图幅边界生效，失败保留原报告。
4. 在 `map_validation.py` 集中生成整套PDF与HTML目录，由普通出图和重绘共同调用。合并失败不得宣称整套输出成功。
5. `SamplingWizardPane.cs` 增加逐幅比例尺与自动恢复、当前图/整套重绘；状态和停止复用 WorkbenchJobService。比例尺变更清除设计确认。
6. 相关 Python 测试、C# Roslyn编译、示例区真实图件重绘与数据几何前后核对；未参与编写的审查者审核最终diff。

共享边界：保留前轮4文件修改和1667项暂存树，不提交；新产物输出到新目录。未完成阶段不得宣称交付。
