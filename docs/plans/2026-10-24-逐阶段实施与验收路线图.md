# ArcGIS Pro 补充耕地插件：逐阶段实施与验收路线图

日期：2026-10-24。目标是让未熟悉 ArcGIS Pro 的人员按向导完成资料检查、影像查看、地块定位、单元与采样设计、规范出图和成果核验。

## 阶段门规则

每阶段先实现、再按本阶段验收表复核，只有本阶段必需项全为 PASS 才开始下一阶段。FAIL 必须修复；NEEDS_REVIEW/UNVERIFIED 需补证据或人工确认。允许形成内部预览，但它不能替代业务通过或正式报件条件。用例、实际运行、输出读回和人工截图分别留收据；文件存在或构建成功不能单独判通过。

## 功能级详细设计（2026-10-25；唯一实施排期）

**目标：** 用户只需完成“选资料 → 自动准备 → 预览确认 → 导出成果”四步。每个自动结果都显示状态、依据和下一步；规范硬要求、软件建议和人工判断分开。此路线图是唯一实施顺序；模块文档保留为规则或技术证据，不另起平行排期。

**架构：** ArcGIS Pro 3.1 Add-In（C#）负责面板、定位器和实时地图操作；Python/ArcPy 核心负责数据发现、空间处理、规则检查、出图与报告；workflow.py 管阶段依赖与恢复；离线 MCP 调用 Pro Python worker，实时 MCP 仅转发到当前 Pro 插件。原始输入保持只读，处理结果写工作副本并保存输入指纹、来源和操作状态。

**技术环境：** ArcGIS Pro 3.1.5 / ArcPy Python 3.9.16；C# Pro SDK 与 net6-windows；系统 Python 3.12 运行轻量契约回归；FileGDB、JSON、CSV、JPG/PDF/PNG。没有 Pro 环境的测试不得代替 Pro 实机验收。

### 四步主界面行为

1. **选资料**：允许使用当前地图或选择一个资料目录；用户只需确认图斑层、业务编号字段、项目范围和有歧义的辅助层。显示“地图共 N 块 / 本次选中 M 块”；空选集、定义查询或无效路径须显眼提示。
2. **自动准备**：按已保存角色发现数据、检查坐标与字段、检查影像、生成单元/设计点候选和管理图层组。硬错误先停在准备阶段；资料缺少但可预览时给出临时候选及缺项清单。
3. **预览确认**：地图上按业务编号定位、上一块/下一块、异常跳转；逐单元查看影像和点位。点位吸附调整后即时复检；用户确认的是“设计候选”，不能确认成实际采样事实。
4. **导出成果**：先检查必需项，再生成两类报件图及相应清单/表单/标签；导出后重开文件、显示缩略图和逐图结果。技术通过与业务审核分列；不得把 NEEDS_REVIEW 或 UNVERIFIED 汇总成通过。

## 2026-10-28 自动图册与简化入口

目标：选择当前图斑或资料目录后，一次生成已排版的设计预览；复用现有采样、影像与制图出口。主界面保留资料、预览、确认导出，技术设置折叠。图册按当前原始地块规划，空间分区与采样合组分开。

1. `sheet_plan.py` / `tests/test_sheet_plan.py`：先写失败用例，再实现确定性的总览、空间分区、逐原始地块目标及完整图框范围；验证9地块合成7采样组仍输出9张采点图、顺序稳定、无漏块或重复、单选只出本次范围。
2. `workflow.py` / `map_worker.py` / `map_export.py`：取底图前消费图册计划；位置图优先可用的授权矢量底图，采样图使用影像；目标明确过滤原地块与点位，不因适配影像裁掉计划地块。保留当前模板、左下图例及独立导出进程。
3. `oneclick.py` / `GridSampling.pyt` / `workflow.py`：增加完整图件预览动作，图面标为设计预览，任务停在待确认；正式导出沿用指纹与人工设计确认，不重算有效采样、不把预览文件作为正式缓存复用。
4. `SamplingWizardPane.cs` / `triage.py`：自动读取当前源参数、已存服务密钥、默认输出新目录；优先选可识别的原始图斑，保留可见的处理范围。预览前不以单位/签审信息阻断，生成后直接展示图件和缩略图；项目/影像/技术设置折叠，元信息改动仍使预览失效。
5. 先跑纯计算和接口正反测试，再用Pro Python真实跑一块及多块图册、复用与确认导出；看图核对地块、点位、整幅底图覆盖、图例与文字。编译、打包、读回和安装后验证实际入口。失败可回到已完成阶段，不覆盖原数据。

新增代码均由现有模块承接，不复制历史atlas脚本或写死A—D/9地块/旧点位；历史图册只用于比对。风险为错误范围、合组后漏图、底图不盖满图框及预览误交付，分别以选择守卫、逐原始地块计划、图框范围取图和明确预览标记/正式导出门控验证。移机和新手现场验收仍由用户安排。
