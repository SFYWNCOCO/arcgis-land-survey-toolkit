## 实施纪律

1. 每次改动限于本插件、其验收脚本及本计划直接依赖的测试。
2. 对应的失败对照先红后绿；优先用 Python 3.12 可运行的纯逻辑契约测试，再在 ArcGIS Pro Python 3.9 环境跑 ArcPy 集成流程。
3. 输出目录只写当前任务；安装包使用新文件名；不覆盖源影像、源矢量、原工程或已有成果。
4. 任何来源或精度未知都保留 `UNVERIFIED/NEEDS_REVIEW`；网络服务访问失败、预算降层和无覆盖分别给出原因。
5. Pro UI、在线影像可用性和另一台机器验证只能在目标环境实测；静态测试不冒充实机验收。
