# 高清影像、自动图层与规范出图设计方案

日期：2026-10-23  
范围：广西补充耕地质量验收 ArcGIS Pro 采样助手第一阶段

## 目标和边界

把资料接收、图层准备、评价单元确认、布点、出图、质检和成果导出串成适合 Pro 新手的流程。界面收敛为“选资料 → 自动准备 → 预览确认 → 导出成果”。本阶段交付采样设计和外业准备资料；不自动给出质量等级或替代业务审核。

影像有三条入口：接收业主/测绘单位 DOM；查询并预览已授权的在线服务；为无人机补测生成范围、缺口和交付要求包。在线像元间距、输出像元大小、传感器原生 GSD 和位置精度分开记录，来源、日期、许可或精度未知时标为 `UNVERIFIED`。放大、重采样、缩放级别或导出 DPI 不能证明精度达标。

已有图层按数据源和稳定标识接入，不以图层显示名作为唯一键。所有派生数据写入新工作副本，并保留图斑—单元—网格—样点关联和变更记录。缺资料时可生成标明待确认的预览，正式导出前须完成规定检查。

## 用户路径

1. 选择当前地图图斑或资料目录；核对当前选择范围，并识别图斑、已有单元、点位、土壤、地貌和影像候选。
2. 自动检查坐标系、字段、覆盖、时相和来源；用户在多候选时确认一次。规则齐全则生成单元候选，缺项则以原图斑构建临时候选并列清缺项。
3. 预览总览和逐单元图；可按编号搜索、上一块/下一块、跳到问题。单元确认后生成编号并同步样号。移动点位后立即重算空间关系、覆盖和间距。
4. 导出位置图、采样点位布置图 JPG，以及复核 PDF/PNG、工作 GDB、点位清单和适用表格/标签；附逐幅缩略图与检查报告。

## 模块设计

- `acceptance/imagery.py`：DOM 接入、授权服务查询/下载、覆盖探测、按标签保存清单、来源隔离缓存和影像质量待核状态。
- `acceptance/oneclick.py`：资料探测、当前选定范围、项目副本、单元/采样、逐单元影像、需求包、阶段收据和下游执行。
- `acceptance/map_worker.py`：可复用内置模板，创建有角色顺序的管理图层组；辅助网格/中心默认隐藏。
- `acceptance/map_export.py`：逐图幅严格应用筛选/影像切换，输出 JPG/PDF/PNG，并读回文件与版面要素；失败单幅显式失败。
- `addin/AcceptanceAddin/SamplingWizardPane.cs`：四步主界面、重名图层消歧、用途映射、候选预览和任务继续入口；高级参数折叠。
- 安装包：模板、样式、规则、图层角色描述和说明随 Add-In 发布，不依赖开发目录绝对路径。

## 验收状态语义

数据、图层、布局、影像、导出五类分别产生 `PASS`、`FAIL` 或 `NEEDS_REVIEW`，并携带目标、检查项、证据和修复提示。自动技术检查通过不代表业务审核通过。影像位置精度与来源许可需要可追溯的证明材料，不以图面文字或像元大小代替证明。

## 依据

- 《广西补充耕地质量验收作业指导书（v1.1）》§6.1、§6.2、§10.2、附录 I；采样图以影像为底图，比例尺“不小于 1:10000”为建议。
- 《补充耕地系统审查技术要求》物理页 21、62、78：适用系统报备环节的影像精度及禁飞区替代资料要求。该要求不扩展成所有采样图一律 `GSD ≤ 0.2m`。
- Esri World Imagery 元数据说明：[官方说明](https://support.esri.com/en-us/knowledge-base/how-to-view-the-world-imagery-basemap-metadata-in-arcgi-000018129)。服务覆盖、来源、拍摄日期和分辨率会随位置变化，逐地块核实。
