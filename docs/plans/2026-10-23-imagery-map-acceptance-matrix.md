# 规范与验收测试矩阵

状态说明：`PASS` 为自动检查通过；`FAIL` 为有证据的自动失败；`NEEDS_REVIEW` 为需人工/现场/来源证明确认。矩阵本身不代表对应检查已经执行。

| 面向 | 检查项 | 自动证据 | 反向/待核对 |
|---|---|---|---|
| 影像 | 来源、拍摄时间、位置精度、像元间距、输出像元、许可分别记录 | 每个图幅可回读 source manifest | 无来源/日期/精度证明必须标 `UNVERIFIED`；重采样及 DPI 不能通过精度门槛 |
| 影像 | 覆盖、NoData、缺瓦片、占位图、解码错误 | 瓦片探测、栅格有效像元比例、输出统计 | 人工确认黑白/低纹理区域；网络超时不得伪装成无覆盖 |
| 缓存 | 服务、图层、样式/版本和授权凭证隔离 | 同坐标服务 A/B 缓存路径不同 | key 不写入清单/日志；服务变更不复用旧瓦片 |
| 数据 | 编号唯一、几何有效、坐标参考已知、关联有效 | GDB 与报告读取检查 | 空/重复编号、错坐标、缺字段构造对照 |
| 范围 | 图层来源、稳定标识、同名图层、选择/查询范围明确 | 处理前显示全量数与本次数量 | 同名层不可静默选第一层；筛选失败逐图失败 |
| 采样 | 每单元至少 3 点、每图斑至少 1 点、有效归属、通常间距 15m | 网格和空间关系检查结果 | 小图斑可例外但必须审核；5m 避边是可调建议 |
| 图层 | 角色、连接、顺序、可见性及查询范围 | 项目图层组结构/图层数收据 | 节点与中心默认隐藏；连接丢失即失败 |
| 布局 | 图名、单位、日期、投影、比例尺、指北针、图例、区位框 | 文字/元素存在性检查和 PDF 读取 | 纸面压盖、符号清晰度须逐图看缩略图 |
| 比例尺 | 采样图建议 1:10000 或更大比例尺 | 输出提示级别 `practice` | 1:15000 等不得因超建议单独判 FAIL |
| 影像精度 | 系统报备适用环节才检查“优于 0.2m”及禁飞区替代材料 | 记录证据路径及用途 | 不从在线层级、输出像元或图面注记推出精度通过 |
| 导出 | JPG、PNG、PDF 可重新打开；图幅数、页数、尺寸和目标正确 | 每幅文件校验、摘要和缩略图清单 | 缺指北针/单位/文件损坏/筛选失败注入 |
| 任务恢复 | 任务输入指纹、阶段、取消/失败状态和产物清单 | 状态文件原子写入、续跑读回 | 输入改变时失效相关下游；取消不丢已完成阶段 |
| 可移机 | 中文/UNC、断网、无开发目录、离线 DOM | 复制安装包及离线测试项目 | 另一台支持版 Pro 未测不得标通过 |

## 指导书依据映射

- §6.1、§6.2：评价单元和采样布点规则；实际执行需结合地块均匀性、代表性及现场条件。
- §10.2、附录 I：位置图/采样点位布置图的图名、单位、时间、投影、比例尺等表达；采样比例尺为建议属性，影像底图按条款使用。
- 系统审查技术要求物理页 21、62、78：仅对适用的系统报备资料核对正射影像精度及禁飞区替代资料。
