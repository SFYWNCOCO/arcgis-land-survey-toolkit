# 图斑合并与画线分割

目标：在当前地图选择原图斑，预览几何编辑结果，确认后作为新的采样来源；可取消候选或撤销回上一来源。源图斑和旧采样任务不改写。

架构：现有工作台增加一个折叠编辑区，独立 `ParcelEditingPanel.cs` 承接选择快照、候选图层及确认/撤销；现有面板仅接收新来源并重建任务绑定。新增 `ParcelSplitTool.cs` 只负责绘制分割线。Python Toolbox 调用独立 `acceptance/parcel_edit.py`，复用字段识别、项目参数和原子JSON写入。

1. 后端校验选择、投影坐标、属性冲突；只接受相邻无重叠图斑合并，或一条线将一块分为两块。新输出复制全部来源记录，候选临时编号用PE_ID，原始地块关联用PE_ORIG保留；已有正式单元失效重建。
2. 比较编辑前后覆盖、面积、部件及几何检查；保留源/候选内容指纹。确认和撤销校验内容与状态，拒绝过期结果。不替用户判定正式地块编号或业务同质性。
3. 沿用项目制图参数和地理辅助资料，重写几何编辑影响的排除规则，撤销受影响采样分组和旧单元点数/图幅尺度；配置变化列入候选报告。未支持的身份映射明确拒绝。
4. C#工具捕获当前选择与地图，候选叠加后供人工查看。确认才切采样来源；取消恢复图层可见性；撤销重新绑定未变化的上一来源。运行复用工作台单写任务门禁。
5. 单元测试覆盖配置迁移和请求非法值；Pro/ArcPy实测相邻合并、分割、撤销、面积守恒、源数据未变和内容变更拒绝；动态GP入口执行，并跑相关回归、编译和包内容检查。
6. 独立审核最终新增差量和调用链，通过后才安装；不提交，不改原1667项暂存树。桌面点击链如受宿主限制，明确记录未验证范围。
