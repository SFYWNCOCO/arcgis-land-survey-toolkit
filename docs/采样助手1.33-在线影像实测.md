# 采样助手 1.33：直接连接在线影像

2026-10-24。针对“没有影像资料，需要像 ArcMap 一样直接接在线影像”的实际需求，本版优先完成天地图连接、当前在线图层接入与地块影像预览。无需先取得本地 DOM。

## 怎么用

1. 安装 1.33 并重启 ArcGIS Pro；打开真实图斑，进入“补充耕地验收 → 采样助手”。
2. 选择图斑和本次范围。影像来源选“天地图影像”；当前电脑已加密保存密钥，会自动读入。其他电脑需自行填写，再点击“记住天地图密钥”。密钥不随安装包发送。
3. 点击“连接在线影像并预览地块”。侧栏显示本次范围首块图斑，红线为边界；这一步不代表整个项目均已检查。
4. 核对影像后点击“自动准备并加载地图预览”，按已有四步向导确认并导出。逐单元继续检查有效像元及来源，缺项保留待核。

也可点击“使用当前地图影像”，读取已添加的公开或已授权 ArcGIS Web Mercator 缓存 MapServer；可直接输入服务地址。需要 token 的服务须填其自己的 token，天地图密钥不会自动发送给其它服务。其它瓦片服务可由管理员提供 XYZ/Web Mercator 配置 JSON。动态 ImageServer、任意 WMTS 矩阵和门户登录态尚未完整适配。

## 已经实测的结果

- 使用用户提供的示例区真实图斑，天地图第 18 级取得 20 张 JPEG 瓦片，无下载失败；下载像元间距约 0.5468 米。真实动态 GP 调用约 5.15 秒完成地块边界预览，有效像元掩膜在该图斑范围内覆盖比例为 1.0。
- 天地图实际 GetCapabilities 返回 w 矩阵 1—18 级。修复了请求不支持的第 19 级、缺少 STYLE 参数及请求头导致的拒绝；没有把这些错误认定为用户密钥无效。
- 同地块的 Esri 实取也成功；第 19 级抽样返回已知占位图，第 18 级可用。服务声明分辨率与下载像元间距分别记录，不把服务声明推导为位置精度。
- 纯 Python 与规范契约 296 项通过、7 个 Pro 专用模块跳过；Pro 定向 69 项通过、1 项 PDF 纸面尺寸用例因未安装 PyMuPDF 跳过。C# 已在 Pro 3.1.5 SDK 实际编译。
- 两轮独立审查的服务参数、预算绕过、单元服务指纹、凭证编码和透明瓦片问题已添加失败对照并修复；代理 Request 被原地改写的问题有独立反例，直连重试会重建请求且继续验证 HTTPS。

本机收据：`temp/天地图真实影像验证_20261024_084207/在线影像预览报告.json`。输入、范围及检查方式均在报告中记录；本示例只代表所测地块。

## 保存与检查

密钥用 Windows 当前用户 DPAPI 加密，侧栏输入框遮罩；缓存和任务指纹只记录凭证摘要，服务凭证不会写入源码或影像报告。更换电脑/Windows 用户需重新填写。服务返回 401/403 时不换路尝试绕过；网络连接失败、预算受限、无覆盖及解码错误分别记录。

导出已接入实际像素尺寸、DPI 元数据、PDF 页数/纸面尺寸和布局边界/文字溢出/包围框相交检查。包围框相交标待人工看图，不直接等同实际文字压盖。Pro 内没有 PDF 尺寸读取器时明确待核；不冒充尺寸通过。
