# 真实数据审计差距与修复记录

日期：2026-10-20  
依据：广西《补充耕地质量验收作业指导书》v1.1、ArcGIS Pro 3.1.5 / Python 3.9.16 实测、荔浦公开案例包。  
范围：数据接入与成果汇交代码审计；不是正式项目验收结论。

## 真实样本实测

荔浦案例是永久基本农田生态与农业案例，不是补充耕地验收项目。它可用来测试真实 GIS 文件读取、坐标系审计、矢量接入和栅格预检，不能证明地块测量精度、采样合规或质量等级结论。

- 公开包解压后101个文件，共147,292,122 bytes；本地压缩包34,067,769 bytes，SHA-256 `19CB2E34AABD1D98670ACE91F849C356C33A611D507D0F540CA1E879F5405CA3`。
- 包内既有 Shapefile 和 GeoTIFF，也有 ASC、表格、文档和普通 JPEG。边界矢量为 CGCS2000 三度带第37带 WKID 4525，部分样点/水系为 WGS 84 WKID 4326；6个 GeoTIFF 可读自定义 WKT、WKID=0，2个 ASC 坐标系未知。
- 当前插件的栅格预检读到19项且无读取错误：11张普通图片标记缺少地理配准信息待核；2幅 ASC 阻断空间分析；6幅 TIFF 标记自定义 CRS，需要核对来源和转换依据。
- 真实反向环境试验将 ArcGIS Pro `outputCoordinateSystem` 故意设为 EPSG:4326，再导入修仁镇面；输出仍为1个要素、WKID 4525，说明导入流程不再静默继承错误工程环境。
- 官方数据页说明此数据集由101个文件组成并要求按指定格式引用；进一步传播/增值用途需遵守数据平台条件。原始包不进入 Add-In 分发文件。

## 代码审计发现及已修复项

| 风险 | 修复或处理 | 验收证据 |
|---|---|---|
| ArcGIS Pro 输出坐标环境可能影响矢量/JSON转换，数量正确也不代表 CRS 正确 | 转换时显式设置输出空间参考，完成后用 Describe 读回并与目标空间参考比对；失败进入输出回滚 | 真实荔浦面在错误环境下导入，读回 WKID 4525、1/1要素 |
| 图层选择集或定义查询会让部分矢量被导入，源/目标数量校验仍可能通过 | 导入前拒绝活动选择集和定义查询，提示使用未筛选源要素类 | ArcPy 入口保护及合同测试 |
| JSON和Shapefile源可能在导入过程中被修改；Shapefile由多个配套文件组成 | JSON单文件和Shapefile同名配套文件在导入前后核验SHA-256；变更则回滚 | Pro Python测试覆盖文件指纹和配套文件清单；真实数据测试覆盖 Shapefile 成功路径 |
| JSON临时成果清理失败后，正式输出回滚失败路径可能丢失 | 组合报告临时清理和正式输出清理错误 | 代码路径和失败分支回归测试 |
| FileGDB创建失败留下无法被 ArcPy 识别的残缺目录，影响重试 | 仅在本次调用创建目标的前置条件成立时，同时检查物理目录和 ArcPy.Exists 并尝试回滚 | Pro Python项目建库回归测试 |
| 附录C部分字段值域仅提示人工复核；汇交检查未调用附录C质检 | 自动核查 SFYKT/SFFK/SFZPJ 是/否、BCFS 代码及 BCGDLY 来源值，并在汇交报告纳入附录C结果 | 新增值域断言；全套144项回归通过 |

| 混合样 `SAMPLE_ID` 错填仍可能通过，未关联/越界点可能计入覆盖数，工具未读取评价单元面 | 生成与质检都要求评价单元面；生成前检查图斑归属，质检核对图斑/点位的单元空间关系和 `SAMPLE_ID=评价单元编号`，只有有效关联点参与点数与间距统计 | ArcPy 3.1.5 合成工程运行；样品号错误、无关联点和空间外点回归断言；QA JSON记录原始点数与有效关联点数 |
| 容重设计未显示无调查点的评价单元 | 缺质地构型调查点的单元列 `NEEDS_PROFILE_POINT`/0个候选；质检将该单元0/3判为`FAIL` | ArcGIS Pro 3.1.5 两评价单元实际 GDB 探针 |

## 按指导书的剩余差距

条款页码按用户提供PDF实页与印刷页双列记录。具体要求以PDF原文为准，以下“自动检查”描述插件可机械核查的部分。

### 10.1 数据库成果、附录C/G

- 已能检查 FileGDB、规定图层、评价单元 Polygon/坐标系、Appendix G字段名称、类型、字符串长度和别名；项目 QA 能检查部分 Appendix C字段、必填项、基础数值范围、重复标识码、多部件几何和评价单元面积上限。
- 附录C注4/5/7的明确值域现已加入：三个“是否”字段、“补充方式”和“补充耕地来源”。仍需人工判断项目类/非项目类与代码关系是否填对。
- 尚未自动核验附录C/G数值字段的小数精度、G表结果值域/字段单位、报告与数据库评价结果一致性、日期字段源值含义。FileGDB numeric `Field.length` 不等同附录表格的十进制宽度，不能简单照抄检查。
- 评价单元的地形部位、土种、来源和现状同质性，以及不同项目不得合并，需要真实源图斑和资料审查。国土变更/鉴定图斑原样移交、与正式源库一致、细缝连接判断仍依赖权威源件与人工影像复核。

### 10.2 图件成果

- 当前汇交检查可查指定图件文件名/存在性，模拟报告的地理位置图和采样点位图已有北箭头、比例尺、边界及图例等版面元素。
- 文件存在不等于图面合格。地理位置图道路、水系、居民点、行政边界和制图信息；采样图图名、制图单位/时间、坐标系、比例尺、北箭头、影像底图及点位表达，需要逐张人工核验。当前人工审核项未逐项钉住采样图全部版式元素。
- 报告里的图为模拟成果；公开影像底图来源和许可需按实际出图用途确认，不能拿模拟项目图件作为实测验收成果。

### 10.3 文字成果

- 目前检查文件是否存在、扩展名和大小，不读取正文结构、附表、条款引用、表间一致性、签章和版本。
- 附录I将县级报告列为 DOC。当前工具允许 DOCX，是兼容性选择，不应声称完全严格匹配目录列示格式；正式项目需按主管部门要求提交，或取得允许 DOCX 的书面口径。
- 需要增加或人工执行附录L/M/N内容完整性清单、意见表要素及报告/数据库/检测报告数值一致性复核。

### 10.4 附件成果

- 必交和条件附件按项目类型、污染报告适用性、复评状态检查名称/存在性；照片至少要有 JPG 文件。
- 尚不自动识别PDF正文、三方身份/签章、照片类别及数量与样点的关联、照片定位真实性、样品交接与检测报告样号一致、CMA证书范围是否覆盖检测项目。污染报告适用性仍需留存判断依据，不可只依赖 manifest 布尔值。
- 建议把人工审查从单一勾选改为“文件路径/页码或影像ID + 审核人 + 审核日期 + 结论”，便于追溯；本轮未伪造这些证据。

### 采样布点与检测机构

- §6.1要求同地形部位、土种、补充耕地来源和现状划分评价单元，按面积、图斑数、地形、客土来源和调查条件确定点数，每图斑至少一点并均匀布点。技能现有人工判定清单；生成器只给最低候选，不把地形、来源转成未被规范支持的点数公式；均匀性、田边避让、可达性和代表性仍由现场人员审定。
- §6.2.4要求混合样0–20 cm、每样至少3个分样点、通常不少于15 m间距；小图斑要覆盖且避开田边。容重按质地构型点附近2 m范围布3个平行点、间距2 m并用100 cm³环刀。程序核查评价单元/图斑/点位空间关系和最低点数，不验证现场真实点、采样深度执行、避边及样品交接链。
- §6.3.1要求县、市两阶段分别委托不同检测机构。不同登记字符串只证明填写值不同；机构法人独立与 CMA检测能力必须有证书/登记资料人工核验。未检测书面说明状态不被描述为规范豁免。

## 公开数据来源及限制

- 荔浦案例：[官方数据集页面](https://geodoi.ac.cn/WebCn/geodoi.aspx?Id=3335)，记录101文件、约140 MB未压缩、压缩包约32.4 MB，并给出数据引用格式。下载包仅用于本地评估，不打入插件包。
- 广西 OSM：[Geofabrik广西页](https://download.geofabrik.de/asia/china/guangxi.html)，2026-10-20抓取的最新包约126 MB SHP/127 MB GPKG；2026-10-18固定日包分别为132,579,446和134,083,497 bytes，许可ODbL 1.0。它不能代替法定地块线。
- CCPD-V1：[ScienceDB数据页](https://www.scidb.cn/en/detail?dataSetId=22447272804f429fbd7197b668190ccc)。本轮未下载35 MB矢量包或约4.9 GB影像标签；文件精确字节数尚未本地复核，网页或下载目录的API快照需补入证据包。
- 官方遥感链路与限制见 [`真实数据包调研`](real-data-package-research-2026-10-20.md) 和 [`荔浦Sentinel分析`](lipu-real-data-gap-analysis.md)。公开遥感数据不能证明现场土地质量、采样结果或验收结论。

## 本轮复核结果

- ArcGIS Pro Python 3.9.16：截至1.19采样闭环，全套149 passed。
- ArcGIS Pro 3.1.5真实数据：矢量错误工程坐标系反向试验通过；栅格包19项无读取错误，11/2/6分别处于无配准图片待核/未知CRS阻断/自定义WKT待核。
- Add-In从1.18更新为1.19，核心Python源按打包脚本哈希核对后已重打包并注册到当前用户。ArcGIS Pro 3.1.5合成工程采样链得到`NEEDS_REVIEW`，字段/空间关系/间距按预期读回；另以两单元GDB实测无调查点单元明确失败。需重启ArcGIS Pro验证Ribbon加载和按钮链；本轮未声称UI已通过。
- 本轮没有使用公开数据训练或校准地力模型；没有下载4.9 GB CCPD标签数据，也没有取得完整广西补充耕地验收项目原始包。正式结论仍须依据经授权的项目CAD、RTK、图斑、采样、检测和签章材料。
