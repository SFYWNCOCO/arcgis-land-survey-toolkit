# 底图四类与 AI 绘图（1.82）

日期：2026-11-03。范围：`land_survey_toolkit` 的 MCP 桥（`ai/tools.json` + `ai/addin`）与 Python 底图数据层（`acceptance/`）。
背景：用户指出插件缺少「绘图能力」以及「DEM 底图、影像图、矢量图、区图、位置漂移校准」。本轮按确认范围全部补齐，工具目录 47 → 53 项。

## 0. 结论

- **底图**：统一 `add_basemap` 支持 6 类来源——天地图影像/矢量/地形晕渲、高德卫星/矢量、高德行政区划区图（县/乡界线+驻地）。天地图按当前地图范围生成 CGCS2000 目标投影的本地快照（也可尝试会话底图）；高德瓦片在快照阶段**逐像素**由 GCJ-02 纠偏到目标投影；区图以矢量图层加载。
- **漂移校准**：新增只读 `calibrate_basemap_offset`，给出范围内中心/四角 GCJ-02 偏移、变化量与算法说明；高德快照默认走纠偏路径，未纠偏时拒绝生成 CGCS2000 成果。
- **绘图**：新增 `draw_features` / `list_drawings` / `clear_drawings`。默认只预览（不写数据）；`confirm=true` 才写入指定要素图层或 appdata 临时 GDB 的「AI绘制（临时）」层；撤销只按本进程登记的批次/图层，绝不按 `where` 删业务要素。
- **边界**：高德卫星/矢量、区图行政界线均标记为参考底图（`REFERENCE_ONLY`），不当作 CGCS2000 正式成果；正式报件仍须项目 DOM、三调/民政官方界线与影像精度证据。GCJ-02 纠偏是公开近似算法，不能替代控制点配准。

`add_basemap` 的 `level`（县/乡/县乡，默认县乡）与 `keywords`（县/市名或 adcode）仅对 `amap_district` 生效，其他来源传入会明确拒绝；`labels` 仅对天地图来源生效，高德/区图在响应里回显 `labels_applied=false` 与 `ignored` 列表。

`list_basemap_sources` 每行返回 `status / coordinate_system / can_load_into_map / map_mode / correction / positional_accuracy_status`，不返回密钥。`remove_basemap` 只移除受管底图图层，不碰业务图层。

## 2. 位置漂移校准（GCJ-02 → CGCS2000）

- `acceptance/gcj02.py`：WGS84↔GCJ-02 正反算（迭代反算，容差 ≤1e-9°）、椭球米制偏移、中心+四角偏移表。
- `acceptance/basemap_offset.py`：纯数学 CLI，输出中心/四角 `east_m`、`north_m`、`distance_m`、`variation_m`、`max_offset_m` 与算法说明。
- 高德快照纠偏（`imagery.prepare_imagery(..., gcj02_correct=True)`）：输出目标 CRS 网格 → WGS84 → GCJ-02 → WebMercator 米制 → 双线性采样；预乘 alpha，越界 alpha=0，并按实测最大偏移外扩请求范围。`meta.correction` 记录方法、是否应用、中心/最大/变化量估计与精度声明。
- 实测（Pro Python 3.9.16 / GDAL 3.4.0e）：逐像素纠偏结果相对 arcpy 独立反投影最大 0.499 px、平均 0.346 px；同一数据**不纠偏**时整体偏移 175.9 px，说明纠偏不是整体平移冒充。广西范围内偏移量约 500 m 级，范围内变化约 2 m。
- 明确限制：公共 GCJ-02 算法未经控制点检核，纠偏后也不得称“精校正”；正式成果须控制点配准与精度报告。

## 3. 区图（行政区划参考）

- `acceptance/district.py`：高德 `v3/config/district`（`extensions=all`；无 keywords 时用 `v3/geocode/regeo` 取 adcode），递归解析县/乡级 `polyline`（`;` 分点、`|` 分环），环按面积与包含关系分主环/内环并转为 ArcGIS 方向（外顺内逆）。
- 输出：`--out-gdb` 内两个要素类 `<name>_区界`（POLYGON）与 `<name>_驻地`（POINT），字段 `ADCODE/NAME/LEVEL/CENTER_LON/CENTER_LAT/SOURCE`；WGS84 建库后 `arcpy.management.Project` 到目标 WKID（基准视为一致，未做七参数，JSON `datum_note` 明示）。
- `legal_status = REFERENCE_ONLY_NOT_LEGAL_BOUNDARY`：高德界线只作位置参考，正式报件必须三调/民政官方界线。
- 本机无高德 Web 服务 Key，因此真实接口未联调；无 Key 时脚本失败并给出中文原因。

## 4. AI 绘图

| 工具 | 行为 |
|---|---|
| `draw_features` | `geometry` 为 GeoJSON 文本（Point/MultiPoint/Polyline/MultiLineString/Polygon/MultiPolygon）；`crs` 默认 WGS84，`MAP` 表示当前地图坐标系；省略 `confirm` 只预览（顶点数、范围、长度/面积、目标，不写数据）；`confirm=true` 写入 `layer` 指定要素图层（属性只允许图层已有字段，禁止 OID/Geometry/GlobalID）或 appdata 临时 GDB 的「AI绘制（临时）」图层 |
| `list_drawings` | 只读：临时层是否存在 + 最近批次（批次号、时间、目标、要素数、OID） |
| `clear_drawings` | `confirm=true` 必填；`target` 为批次号/临时图形/省略=全部；只撤销本进程登记的 OID 或登记图层，临时 GDB 删除前校验路径位于 appdata drawings 根目录 |

- 写入用 Pro SDK `EditOperation.Create/Delete`（编辑会话语义）；临时层用 appdata File GDB + `management.CreateFeatureclass` 创建，避免依赖 GraphicsLayer 的版本差异。
- 登记表为进程内（工程 URI+地图 URI 为键）。重启 Pro 后，已保存进工程的临时层不再可自动撤销，需手工删除 `%LOCALAPPDATA%\ProAiBridge\drawings` 下对应 GDB。
- 预览路径零写入；撤销无 `where` 批量删除路径。
