# 用户提供的网格采样工具介绍研究

## 材料与结论

来源为用户桌面“新建 Microsoft Word 2007 文档.docx”，2026-10-23读取全文与4幅主要配图。其正文为工具宣传/案例介绍，并附规范条文片段和软件截图，不是带完整发布机构、版次和出处的规范全文。“直接满足入库要求”“自动合规”等属于文案主张，不能当作已验证的软件能力或验收结论。

用户确认使用当前 ArcGIS Pro 已有影像。可在现有真实影像上叠加地块、网格和设计点，再输出采样点位图；矢量边界并不生成真实遥感影像。

## 能提炼的功能

1. 单元划分：字段映射绑定土地利用现状、土壤类型、地形部位、补充耕地来源与项目标识。规则分组后产生待审核的拆分/合并候选，记录源图斑对应关系、面积与理由。
2. 网格布点：以确认后的评价单元及图斑关联为输入，配置网格尺寸，选择节点或中心点作为候选；显示覆盖数、间距、避边和不能满足的原因。
3. 分开输出：评价单元、方格网、网格节点、网格中心点、设计采样点；独立SHP/工作库图层及坐标表，图层和编号可追溯。
4. 图件：保留真实影像，红色地块边界、方格网、候选点/确认点分别渲染，按单元输出PDF；图例必须区分网格交点、中心点、最终选择的设计点，不能把全部候选当实采点。
5. 项目配置：显式字段映射、参数保存复用；报告表单作为后续模块，不根据宣传稿虚构调查/检测事实。

## 配图中可直接确认的内容

- 图1的6.1.3片段列出四因素一致、图斑相对集中、不同项目类型图斑不能合并、评价单元不超过50亩；6.1.4片段列出每单元至少3个分样点、多图斑每斑至少1个点，以及按网格节点或中心点均匀布设。片段缺完整版次，正式规则需核对适用指导书。
- 图3展示四因素相关字段下拉映射、单地块最大面积、山地丘陵/平原合并上限。界面默认50亩只是该截图配置，不证明允许任意改动法定阈值。
- 图4展示网格尺寸20米、最少点数3、分区加密参数。20米网格和加密50亩/点不能脱离项目条件当成统一规范值。
- 图2展示用户要求网格、中心点、节点与布设点分层展示，这是明确可借鉴的操作与成果组织方式。

## 对当前工程的影响

- 1.21已新增快速定位、通用地块质检、复制整理与批量PDF。既有插件另有混合样/容重候选点设计及空间质检。
- 当前批量制图保留当前地图中可见影像、网格及点图层；使用者需先加载并核对影像。新制图实际验证的是无网络底图的边界图，现有影像和点位叠加链尚未在用户Pro会话实测。
- 目前不具备本文宣传的四因素自动单元拆分/合并、四套网格成果独立输出以及可视化业务字段映射；不能将现有最少候选点生成器表述为完整网格法成果。
- 用户提供的9块Shapefile具有地块号、项目号、地类、用途和面积，但没有明确土壤类型、地形部位等完整划分依据。不能把PURPOSE“开垦”直接硬映射为规范来源类别，也不能仅凭面积将邻近图斑合并。

## 推荐接入顺序

先核实已有影像的数据源、时相、空间参考和覆盖，加载真实边界；再接收人工确认的评价单元及图斑关联，开发网格及四类成果输出；随后做覆盖、间距、避边和编号质检与影像点位图。四因素自动划分待输入资料齐全后再实现，始终保留人工审核，不自动宣告合规。
