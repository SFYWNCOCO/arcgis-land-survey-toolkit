## 自动出图

1. 选择地图中的原始图斑或资料文件夹，核对可见的处理范围；当前选择和定义查询优先。程序自动读取同目录项目参数、已存天地图密钥，安排新成果目录。
2. 点击“一键生成预览图”：自动布点、先规划图册与比例尺，再取覆盖完整图框的底图，输出总览、空间分区位置图和逐原始地块采点图。空间分区不改变采样合组，超面积拆分仍保持原地块出图关系；大范围地块自动调整到能完整入框的标准比例尺。
3. 侧栏列表切图、点击放大，“整套图件”打开缩略图与缺项清单。技术选项及影像替换折叠；预览前不强求单位、签审信息或人工挑选比例尺。无活动地图也能从资料文件夹出图，地图图层加载是附加步骤。
4. 交付前补齐真实编制单位、确认人并核对设计；本机记住通用单位/人员信息，项目编号和地块分组不跨项目猜测复用。预览图带明确标题并独立保存，正式导出仍校验当前设计指纹，复用有效采样，不将预览文件充当正式缓存。

位置图优先使用已授权的天地图矢量及地名注记，采样图使用影像；本地DOM与全套逐单元DOM可离线运行。PNG调色板先按真实RGBA解码，注记按透明度叠加，不再把颜色索引当灰度。重试共享任务内按服务/版本/密钥摘要隔离的瓦片缓存。图面与资料精度仍分别核验，自动出图不等于验收通过。

## 使用

1. 在“补充耕地验收”功能区点击“打开工作台”。“AI助手”负责对话、底图浏览、地图操作和任务结果；“采样与出图”负责资料范围、项目参数、设计预览、人工确认与导出。
2. AI页输入`/`查看命令，`/sampling`切到采样页；Enter发送、Shift+Enter换行。页签切换保留未发送草稿与表单。
3. 助手默认采用合理的低风险选择继续，不反复要求从多个方案中挑选；只在坐标系、处理范围等关键信息缺失，或涉及覆盖、删除、发布时追问/确认。地理处理执行器保留现有人类确认保护。
4. 采样页仍先准备预览、核对设计点，再确认导出。AI改变了当前选择集/定义查询后，需要刷新采样资料；执行前校验会拒绝旧快照，不会静默处理旧范围。切换工程或地图也需要重新选择来源。
5. 天地图Key在两页共用加密配置。只保存本页编辑过的字段，未保存草稿不会被另一个页面的加载覆盖。高德JS API Key+安全密钥用于浏览，POI Web服务Key单独配置。

天地图预览由插件本机回环代理取瓦片，浏览器页面不携带Key。1.64影像默认18级、普通地图16级，提供放大、缩小、回到打开位置和影像地名道路开关；精度说明按需展开。高德显示上限20级，天地图18级，层级不代表源分辨率。

已用本机配置实测高德普通地图、卫星影像及天地图影像，在同一位置验证缩放、上限、复位与地名开关；天地图18级视口48张瓦片全部加载。该位置天地图目视细节优于高德，不能推广为全区域结论。原始分辨率、拍摄日期、位置精度仍未核实，阿里云源尚未联调。授权XYZ/WMTS配置见[底图接入](2026-10-27-basemap-services.md)。
