日期：2026-10-24。本轮只验证**数据契约、照片落点、回收质检**；QGIS/QField 未安装，QField 工程文件尚未生成。

## 一、已做出的采集包

`temp/外业采集包_20261024_v3/`

- `外业采集.gpkg`：设计点 27、容重点 27、质地构型 9。
- 采集字段：`COLLECTED、COLLECT_TIME、GPS_LON、GPS_LAT、ALT、ACC_M、PHOTO_COUNT、PHOTO、SAMPLE_TYPE、OPERATOR`。
- `设计点清单.csv`：含投影坐标 X/Y 与 WGS84 经纬度 LON/LAT。
- `采集说明.md`：照片张数、样号规则。
- `package_manifest.json`：来源、数量、时间。

设计点全部保持 `DESIGN_ONLY`，空字段不代填。

## 二、已跑通的两件工具

```powershell
# 照片 → 点（EXIF GPS/时间/方位角，就近匹配设计点）
python scripts/photo_geotag.py --photos <照片目录> ^
  --design 设计点清单.csv --out photo_points.csv --geojson photo_points.geojson

# 回传质检（缺点/多号/跨单元复号/偏移/无GPS/照片数）
python scripts/field_return_qa.py --design 设计点清单.csv ^
  --returned photo_points.csv --out 回传质检.json
```

本轮合成验证：27 点各 1 张 + 1 张偏移 30 m + 1 张无 GPS → 落点 `matched 27 / far 1 / no_gps 1`；回收质检 `NEEDS_REVIEW`（偏移、无 GPS、单元照片数不足）；删掉 1 个点后为 `FAIL` 并列出缺点号（金丝雀通过）。

## 三、QField 接入步骤（未在本机验证）

1. 安装 QGIS 3.x 与 QField（Android 或 Windows 桌面版）。
2. QGIS 打开 `外业采集.gpkg` 的三个图层，工程坐标系设为 CGCS2000 3° 带 36（与设计点一致）。
3. 图层属性 → 属性表单，按字段设控件：
   - `COLLECTED`：复选框，默认 false。
   - `COLLECT_TIME`：日期时间，默认 `now()`。
   - `GPS_LON` / `GPS_LAT`：隐藏，默认 `@gnss_longitude` / `@gnss_latitude`（QField 变量）。
   - `ALT` / `ACC_M`：隐藏，默认 `@gnss_altitude` / `@gnss_accuracy`。
   - `PHOTO`：附件控件，存相对路径。
   - `OPERATOR`：文本；`SAMPLE_TYPE`：值映射（混合样/容重/质地）。
4. 另存工程为 `外业采集.qgz`，放在采集包根目录；路径全部用相对路径。
5. 数据线拷贝整个 `外业采集包_20261024_v3` 到手机；QField 打开 `.qgz`。
6. 现场采集后拷回；先跑 `photo_geotag.py`，再跑 `field_return_qa.py`。

## 四、边界

- 设计点不是实采点；`COLLECTED=1` 才能算现场采过。
- 照片硬要求按指导书：每单元全景≥4、近景≥2、工作照 1 张；本工具只统计张数，内容与真实性仍须人审。
- QField 工程需在装 QGIS 后生成并实机打开一次，才可宣称“QField 可用”。
- GPS 变量名以当前 QField 版本为准（`@gnss_longitude` 等），接入时现查。
