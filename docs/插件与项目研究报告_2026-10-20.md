# 广西补充耕地验收插件与公开真实GIS样本研究报告

日期：2026-10-20  
对象：本工具包源码、ArcGIS Pro Add-In、广西补充耕地质量验收作业指导书 v1.1 及公开荔浦样例数据。

## 一、结论

1. 在本次核查的官方仓库与指定版本页面中，没有发现 ArcGIS Pro SDK Community Samples、CAD to GIS Studio 或 sgsR 提供完整中文产品支持或广西验收规则适配的证据。前两者文档/示例以英文为主，sgsR 的 DESCRIPTION 标记 `Language: en-US`；Esri 3.1 Localization 样例演示德语资源组织。此结论只限已查材料，不外推至所有 fork 和历史版本。插件自己的 Ribbon 与主要 GP 提示为中文，广西规则由本项目实现。
2. 已下载并在 ArcGIS Pro 3.1.5 / ArcPy 中实测广西荔浦公开综合数据包。它覆盖真实边界、土壤/水文点线、多种专题栅格和附件，可检验数据接入、坐标系与遥感流程；它不是补充耕地质量验收项目，缺少法定验收边界、CAD/RTK 原始测量、验收采样链、检测/CMA资料及签章报告。
3. 复核广西 v1.1 后修正了附录 C 几何质检：多部件图斑按注 6 判不通过；“细缝连接多个图斑”列为强制人工拓扑/影像核查，不虚构阈值。历史记录见第5节；当前版本、采样闭环和实测见第7节。
4. 遥感接入真实 S3 COG 仍有已复现的 GDAL 3.4 远程 tile 读取故障；故障时工具失败并清理本次运行目录。它不妨碍本地荔浦专题栅格读取，但当前不能承诺大范围在线 Sentinel 数据稳定跑通。

核查口径分成四项：界面语言决定用户能否中文操作；文档语言决定能否直接中文学习；行业适配决定是否具备耕地/CAD/RTK工作流；规范符合性要求有逐条规则映射、测试和人工签审。中文翻译不自动证明业务适配或规范符合。

判断“中文”时区分界面语言、开发文档语言和行业规则：本地化资源不等于完整中文产品，更不等于通过中国验收规范。以上 SHA-1 提供核查快照锚点；需要复核时按日期和 commit URL 读取官方仓库及 LICENSE。

## 三、荔浦真实数据包实测

### 数据构成与 ArcGIS Pro 读取

- 官方案例包：`LipuTaroRiceCase17.rar`，34,067,769 字节（约 32.5 MiB），解包 101 个文件、147,292,122 字节。许可要求引用数据源；不得随插件或报告公开再分发原始数据。
- 内容：6 个 SHP、6 个 GeoTIFF、2 个 ASC、6 个 XLSX、5 个 DOC/DOCX、11 张 JPG、1 个 TXT 及元数据/索引文件。修仁乡真实边界为 CGCS2000 三度带第 37 带（WKID 4525）；土壤样点 130 个、河流 36 条、水质点 5 个等主要矢量为 WGS 84（WKID 4326）。
- ArcGIS Pro 3.1.5 实测：修仁乡面与 130 个土壤点均能导入 FileGDB，回读要素数、字段和 WKID 与源数据相符；公开样点全部落在乡界内的关系检查不代表测量精度或项目采样合规。
- 遥感发现：6 个 GeoTIFF 含可读自定义 WKT（无 WKID）；2 个 ASC 无 CRS，应阻断空间量算；11 张专题 JPG 无常见地理配准信息，只能作为附件预览。自定义 WKT 与 CGCS2000 间转换需来源说明或控制点依据，不能只因坐标“看起来接近”就重投影。

### Sentinel-2 真实在线读取诊断

- 已从 Earth Search 检索到荔浦附近两期 Sentinel-2 C1 L2A 真实影像，并用小 AOI 运行裁片、NDVI、SCL 掩膜与评价单元统计；结果状态保留 `NEEDS_FIELD_REVIEW`，不作为地力等级或验收结论。样本覆盖/统计记录见 `docs/lipu-real-data-gap-analysis.md`。
- 更大 AOI 的远程读取出现 `TIFFReadEncodedTile()` 错误。普通 HTTP Range 请求返回 206，失败 tile 字节长度与 TIFF 偏移记录一致；`tifffile` 可以解码同一 tile，但 ArcGIS Pro 3.1.5 自带 GDAL 3.4.0e 的 `/vsicurl/` 读取仍失败。强制串行 multirange 未解决错误，因此尚不能断言是网络、S3 或数据坏块中的哪一个根因。
- 对策：保持硬超时、失败清理和明确失败状态；后续在同一 Pro 环境对本地完整资产、S3/HTTP 入口和较新受支持 GDAL 版本做对照。运行成功前不把在线大范围处理列为已具备能力。

## 四、规范差距与本轮修复

### 附录 C 几何

广西 v1.1 附录 C 注 6（PDF 第 50 页、印刷页 44）原文要求不能存在多部件图斑，也不能利用细缝将多个图斑连接。旧质检把多部件仅列为复核，与明确禁止条款不符。当前改为：

- 检出多部件后 `geometry_review.status=FAIL`，总质检同步 `FAIL`，并报告图斑 BSM 和条款来源。
- 对细缝连接输出必需的 `NEEDS_REVIEW` 动作提示。由于规范没有提供细缝宽度数值，插件不设置自创宽度阈值。
- 单元测试先复现旧行为失败，再验证修复；ArcGIS Pro Python 使用真实 ArcPy Polygon 几何验证单部件保持人工复核、multipart 得到 `FAIL`。

### 仍需持续补齐的验收能力

| 成果/环节 | 当前可核验内容 | 尚需人工/项目数据闭环 |
|---|---|---|
| 10.1 数据库 | Appendix G/C 图层、字段、部分值域、坐标系、采样点空间规则 | 与法定源图斑核对、数值精度/域完整性、分层同质性、细缝人工核查、业务映射和实采点回填。 |
| 10.2 图件 | 检查交付目录和图件文件存在 | 图面要素、比例尺、指北针、图例、坐标系、底图授权、符号和出图质量仍需版面/规范核验。 |
| 10.3 文字 | 核查报告文件类型与目录 | 正文结构、附表、结论与依据、签字/盖章、图表引用和报告版式仍未自动校验。 |
| 10.4 附件 | 目录/附件类别/文件存在性 | CMA 资质范围、样品交接链、检测原件、照片定位/真实性、适用性及签章仍需人工审查。 |
| CAD/RTK | 格式预检、坐标字段、显式坐标系、投影读取和来源记录 | CAD 控制点及配准残差，RTK 固定/浮点状态、天线高、垂直基准、项目转换参数须以原始资料核实。 |
| 采样 | 可生成和检查设计点的部分空间约束 | 均匀网格、避边、代表性、可达性和现场校正不能由当前几何规则充分证明；必须区分设计和实采。 |

## 六、建议优先级

1. 用户提供脱敏的真实补充耕地项目边界、坐标/测量资料和允许使用的采样/检测表，验证从 CAD/RTK 到数据库的完整链路。
2. 用项目级同一 AOI 完成采样设计、人工校正、实采回填、数据库与图件/文字/附件清单逐项比对。
3. 对远程 Sentinel 读取做本地资产与 Pro GDAL 对照测试，再决定是否支持离线下载/本地缓存入口。
4. Pro 桌面重启后实际检查当前发布包 1.19 Ribbon 和按钮交互，并把 GP 历史、失败消息、结果导航纳入端到端验收。

## 八、2026-10-20采样空间闭环与 Add-In 1.19（发布包基线）

- 按广西 v1.1 §6.1.1–6.1.4、§6.2.4.2–6.2.4.3及附录E复核后，混合样工具现在要求输入评价单元面；生成前核对图斑编号与单元面包含关系。空间质检同时核验图斑、评价单元和点位关系，并检查 `SAMPLE_ID` 必须等于评价单元编号。错误编号判 `FAIL`；无关联、图斑外或单元外点不参与点数统计；报告分别记录原始点数和有效关联点数。
- 15 m以下的点对仍依据小图斑条款进入人工复核，不自动认定例外。QA JSON为每个违规点对提供待填写栏：小图斑依据、全斑覆盖、避边、审核人、日期和证据位置。
- 容重设计现在列出无质地构型调查点的评价单元 `NEEDS_PROFILE_POINT`；独立质检将缺失设计组列为0/3 `FAIL`，不再让有调查点的单元掩盖缺失单元。
- 最低候选生成器不声称确定规范要求的实际采样总量。实际点数仍由专业人员结合图斑面积、地形、补充耕地来源和现场条件审定；均匀网格、田边避让、代表性和可达性保持人工审核。
- ArcGIS Pro 3.1.5 / Python 3.9.16 全量测试 `150 passed`，涉及核心、工具箱语法和 Add-In 契约；合成 ArcPy 工程成功完成建库、评价单元、混合样、容重、空间质检、RTK接入、数据库检查和栅格摘要。另建两评价单元探针，U2没有质地构型调查点时生成端记录 `NEEDS_PROFILE_POINT`、QA端明确0/3 `FAIL`。这些均为合成数据验证，不代表正式项目验收。
- Add-In 升至 `1.19`，共37个包条目；分发包和当前用户注册包 SHA-256 均为 `91AA3774BFC985635420DED221E15B59F4622CF3FD35C1C2B957BB9AB96CB96F`。逐文件打包门禁通过并复用了未变更 C# DLL。未运行中的 ArcGIS Pro 桌面意味着Ribbon视觉加载与按钮点击尚未复测；注册成功和包校验不代替界面验收。
- 领域技能升级至v1.1.0，补充评价单元四项同质条件、50亩原则、移交图层保护、第10章成果清单及人工签认边界。开源结论增加2026-10-20分支 commit 锚点和直接许可证链接。
