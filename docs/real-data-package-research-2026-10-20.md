# 真实地理数据包调研与插件差距

日期：2026-10-20  
用途：为 ArcGIS Pro 补充耕地验收插件找公开真实数据，识别“能测的工程能力”和“仍需正式验收资料验证的业务能力”。本记录区分真实公开样本、演示数据和法定验收源材料。

## 调研结论

公开网络中尚未找到一套完整的广西补充耕地质量验收项目原始成果包，包含项目批复、正式地块界线、CAD/竣工测量、RTK 观测、踏勘和土样台账、检测/CMA资料、签章报告以及完整汇交目录。

目前最有用的是三类可组合的真实公开样本：

1. 广西荔浦综合案例数据，可测同一地区多格式数据读取、建库组织、坐标和属性检查。
2. CCPD-V1 农田地块矢量，可测真实农田地块几何、字段、空间分布和遥感标注工作流。
3. USGS RTK/GNSS 点与县级测量 CAD/TXT 数据，可分开测测量点和 CAD 导入、坐标解释与元数据检查。

这些数据能让插件的 GIS 工程能力接受真实文件检验；没有一项能够证明广西验收规程下的正式地块精度、采样代表性、质量等级或成果合规。

## 荔浦包实际解包与 ArcGIS Pro 读入

根据用户确认，仅下载荔浦案例单包，未下载其他大数据集。

- 原文件：`LipuTaroRiceCase17.rar`，34,067,769 bytes；WinRAR 完整性测试通过；SHA-256 为 `19CB2E34AABD1D98670ACE91F849C356C33A611D507D0F540CA1E879F5405CA3`。
- 为插件后续实测保存的本地副本位于 `testdata/public_lipu_case17/`，原始压缩包与此前研究归档的 SHA-256 一致；按数据平台条件仅用于本地评估，不打入 Add-In 或公开再分发。
- 解包后：101 个文件，147,292,122 bytes：6 个 SHP、6 个 TIFF、2 个 ASCII 栅格、6 个 XLSX、5 个 DOC/DOCX、11 张 JPG、1 个 TXT，以及 shapefile/raster 辅助索引和元数据文件。
- 矢量图层：荔浦市边界 1 面、修仁镇边界 1 面、河流 36 线、水质样点 5 点、单样点 1 点、土壤样点 130 点。
- 坐标系确实混用：市/镇边界为 CGCS2000 3°带第37带 WKID 4525；河流与样点为 WGS 84 WKID 4326；TIFF 为 ArcGIS 可读取的 `Sphere_ARC_INFO_Lambert_Azimuthal_Equal_Area` 自定义投影，中心经线 105°、原点纬度 35°、球半径 6,370,997 m，但无 WKID（0）；两张 ASCII 栅格没有坐标系定义，ArcGIS Describe 返回 Unknown。
- 插件核心在 ArcGIS Pro 3.1.5 中直接运行 `inspect_vector` / `import_vector_copy`：成功将修仁镇面（1 条、WKID 4525）和土壤样点（130 条、WKID 4326）复制到新建的临时 FileGDB，数量与坐标系读回一致，源文件保留。此处验证的是 Python 核心函数，不等同 Ribbon 按钮或 Add-In UI 端到端实测。
- 只读点面关系检查中，把修仁镇面投影到 WGS 84 后检查，130/130 个土壤样点落在镇界内。两套数据本身基准不同且未应用坐标基准转换；该结果只说明样点与案例区位置相符，不作测量精度结论。
- ArcPy 从边界计算的修仁镇测地面积约 119.567 km²；案例介绍文字写修仁镇总面积 109 km²，约差 9.7%，需要核对边界版本/统计口径后才能解释，不能据此直接判源数据错误。荔浦市边界约 1,759.672 km²，介绍文字写 1,758.62 km²，两者约差 0.06%。

解包文件和逐文件 SHA-256 清单保存在 `temp/real_data_lipu_20261020`，归档校验及来源记录见 `source_manifest.json`。数据仅用于本地核查；如需再发布或随插件分发，先遵照数据平台共享条款办理。

## 组件型参照数据

- **遥感影像**：此前已读取南宁武鸣附近 Sentinel-2 L2A 小样；本轮又检索了荔浦修仁范围的真实 Sentinel-2 C1 L2A 影像，并与荔浦案例包真实乡镇边界在 ArcGIS Pro 3.1.5 中联跑。修仁小样使用10 m B04/B08、20 m SCL、EPSG:32649；单网格对真实边界的两期共同有效覆盖率为62.5649%，检测到每期395,725个SCL NoData像元，说明需要相邻瓦片拼接和项目区实际有效覆盖检查。NDVI总览已修复为只统计评价单元范围。样例目录为 `temp/real_data_lipu_sentinel_20261020/`，分析及限制见 [`lipu-real-data-gap-analysis.md`](lipu-real-data-gap-analysis.md)。
- **广西 OSM**：Geofabrik 页面于 2026-10-20 读回显示最新 PBF 52 MB、Shapefile ZIP 126 MB、GeoPackage ZIP 127 MB；固定的 2026-10-18 日包分别为 54,825,518、132,579,446、134,083,497 bytes。页面标注 ODbL 1.0；仅适合作为道路、水系、建筑及部分 `landuse=farmland` 的辅助数据，不能作为法定耕地边界。旧记录“约123 MB”是较早页面快照，已过期。
- **广西官方 1:10,000 DLG 目录**：可作为道路、水系等基础地形的目录/服务核查入口；尚未验证目标乡镇原始矢量的匿名下载权限和具体许可。
- **广西土壤数据**：公开目录有广西 1:1,000,000 土壤类型图，需审核/申请；尺度只适合区域属性参照，不可用来替代项目地块土壤采样。

## 从真实资料看插件当前缺口

| 工作环节 | 真实样本可查什么 | 插件下一步需要补的能力 | 仅凭公开包仍无法完成的验收 |
|---|---|---|---|
| 项目建库 | 多种真实文件、目录结构、源元数据 | 扫描输入包并输出资产清单；保留原文件；记录来源、日期、CRS、编码、校验值 | 项目法定目录、批准项目区和真实地块编码 |
| CAD/测量 | 实际 DWG 与坐标文本、真实点要素 | 先识别单位/投影/轴序/高程基准，再转换；输出配准和残差报告 | 广西 RTK 手簿、控制点、基站、解状态和验收限差 |
| 矢量评价单元 | 真实农田边界形状与属性样例 | 支持字段映射、空值/重复ID/自交/碎片/面积统计，并输出可追溯修复建议 | 法定 1:10,000 或竣工测量边界及项目坐标精度 |
| 遥感解译 | Sentinel 时序与 CCPD 人工标注多边形/栅格标签 | STAC 元数据自动装配、跨 CRS 网格策略、人工校正和变化证据台账 | 遥感不能证明现场耕作、工程完成、土壤质量和采样结果 |
| RTK/外业 | 真实 RTK 与混合测量点格式 | 导入原始点表，区分测量方法和固定/浮点状态，检查精度字段、重复点、异常 Z、坐标转换 | 现场踏勘记录、点位照片、真实采样编号/封样/交接链 |
| 成果汇交 | 目录与异构资产打包 | 产出文件级完整性清单、必交/条件项判定、缺件报告、机器可读处理日志 | 正式报告结论、CMA 资质范围、签章、现场证据真实性须人工复核 |

## 下载与实测状态

- 已按用户确认下载并分析荔浦案例包（归档约 32.5 MiB）；未下载 4.93 GB CCPD 栅格标签、全省 OSM、RINEX 或其他大型样本。
- CCPD 矢量包仍是后续地块几何基准候选，研究页列示 `vectordataset.rar` 35,463,214 bytes；本轮未下载或在本机复核该文件。研究记录缺少可直接复现该精确字节数的目录 API URL/响应快照，因此暂列待复核，不当作本地实测文件量；如后续验证，只取矢量，不取 4.93 GB 标签包。
- 荔浦案例数据已建立归档与解包文件 SHA-256 清单；原始输入未更改。来源归属和共享限制随清单保存。
- USGS 和 Chippewa 候选的下载许可/使用条件需随数据元数据一起保存；未确认具体许可的材料仅做本地评估，不再分发。
- 公开真实数据不能替代用户或委托方提供的授权、脱敏业务资料。取得真实业务资料后，应按 PDF v1.1 第 10 章和附录逐项建立成果清单与验证记录。
