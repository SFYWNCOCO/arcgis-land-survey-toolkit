# 地块工具 1.21

面向 ArcGIS Pro 3.1.x，位于“补充耕地验收 → 地块工具”。四个入口分别为快速定位地块、地块一键质检、地块数据整理、地块批量制图。

## 快速定位地块

1. 激活包含地块的地图，点击“快速定位地块”。
2. 默认查询当前地图的全部面图层，按 DIKUAI_NO、DKBH、DKBM、BSM、PL_NAME 顺序识别编号；无这些字段时使用 OID。也可以选择单个图层及编号字段。
3. 输入39，按 Enter 或点击“查找地块”。唯一结果自动选中并缩放；多个结果显示图层、编号、OID，双击所需结果或点击“定位所选结果”。
4. 定位会打开该图层可见性并替换地图当前选择；隐藏父组仍须开启。切换地图或增删图层后点击“刷新当前地图”。
5. 默认精确匹配；取消勾选后按包含关系检索，最多显示100条，包含查询最多扫描10万条。名称带单引号按文字处理，不拼接用户SQL。

查询遵循图层定义查询，不只查询当前选中的地块。未找到时不会移动视图。

## 地块一键质检

选择面图层及编号字段，指定一个不存在的新成果目录。可选必填字段、面积字段/单位、面积算法、面积差与重叠容差。工具遵循输入图层的当前选择集和定义查询；需要全图检查时先清除选择。

输出 quality.gdb/异常地块、异常清单.csv、面积核算.csv、质检报告.json。异常层保留 SRC_OID、PARCEL_ID、ISSUES；在属性表中选择一行即可缩放核对。未指定的空备注字段不自动判错。空几何会保留问题记录，但空几何无法在地图显示。

源数据的 DIKUAIAREA 与椭球公顷四位小数一致。平面与椭球面积不能直接当成同一口径比较，尤其是在离中央经线较远处。默认椭球面积比较容差0.5平方米只是面积字段四位小数公顷的舍入容差，可按项目口径调整，不能当作法规阈值。

## 地块数据整理

选择源图层及新的成果目录，可选目标坐标系、已确认的基准转换方法、字段规则JSON。跨地理基准未指定转换时停止。原数据不修改，输出 work.gdb/整理地块 与整理记录.json。

保留源属性并新增 PT_G_M2/PT_G_HA/PT_G_MU（椭球平方米/公顷/亩）；目标为投影坐标系时另增 PT_P_M2/PT_P_HA/PT_P_MU（平面口径）。同名字段拒绝覆盖。

字段规则可包含 copy 和 set 数组。copy 项指定 source、target，将原字段复制到新字段；set 项指定 field、type、value，可选length，向新字段赋固定值。type 支持 TEXT/LONG/DOUBLE。目的字段必须不存在；这里不执行表达式或代码。

示例规则：

```json
{"copy":[{"source":"DIKUAI_NO","target":"DKBH"}],"set":[{"field":"CHECK_BY","type":"TEXT","length":100,"value":"操作员"}]}
```

## 地块批量制图

激活用于制图的地图，选择面图层、唯一编号字段、新的成果目录、图名、编制人员和DPI，默认A4横向、300DPI。工具保存当前工程的临时副本，原工程不保存变更；副本使用源数据坐标系。当前地图中的背景图层按其可见性保留，因此网络底图必须可以读取，并由使用者确认适用性。

输出000_总览.pdf及逐地块PDF、制图记录.json、制图日志.txt。编号空/重复时停止；源层在副本中隐藏，由快照层绘制，避免单地块图叠上原始全图。自定义 .pagx 须恰有一个地图框，并包含 Title、PT_META 两个文本元素。

制图由独立Pro Python进程完成，最长截止按地块数设置并不超过1小时。工作进程失败保留失败记录和日志，不把部分PDF当完整成果。成功后清理temp；若ArcGIS仍持有临时文件，将在记录中标注cleanup_pending并提示路径，PDF内容与清理状态分别报告。

## 实测边界

用户已确认使用当前Pro地图已有影像。影像采样图的操作链是：加载并核对影像 → 加载地块及已确认评价单元 → 运行既有“混合样点设计” → 人工调整/核查设计点 → 将点层和需要的网格设为可见 → 在“地块批量制图”中把图名改为“采样点位图”导出。当前模块保留可见图层，不把SHP转成虚构影像，也不包含四因素自动单元划分和四套网格成果的批量生成。

- 新增定位窗口通过本机 Pro 3.1.5 SDK 编译；窗口按钮、实际选中和缩放仍需在加载新包后的 Pro 会话中验证。
- 已使用真实9个地块验证椭球面积，并以合成异常检查重复号、空值、重叠、选择集、防覆盖、源不变、字段整理及动态GP调用。
- 真实出图验证使用关闭网络底图的工程副本，检验地块边界、编号、图名、图例、比例尺、指北针、面积和日期；不证明在线影像底图可用，也不代表正式报件图已审核。
- 此功能为地块数据处理，不自动判定土地权属、验收合格或土地质量等级。
