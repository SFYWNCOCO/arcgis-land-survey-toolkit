# 采样助手 1.32 候选版现场测试

本包用于确认插件在你们电脑上能否操作。已验证 ArcGIS Pro 3.1.5；其他版本需现场记录。无需安装开发工具或 Python 第三方库。

## 包内内容

- `.esriAddInX`：插件安装包，模板、图层样式和核心程序均在包内。
- `离线测试项目/打开这个测试项目.aprx`：两块合成图斑和一份合成纹理 DOM，不含真实项目数据，不得报件。
- `运行离线自检.cmd`：双击自动检查解包依赖、工作副本及 JPG/PNG/PDF。每次创建独立结果目录。
- `现场验收记录.csv`：由操作同事填写。`已执行验证/` 保存本机验证收据；不代表现场验收已通过。

## 开始操作

1. 将整个 ZIP 解压到本地普通目录，保留子目录。关闭 ArcGIS Pro，双击 `.esriAddInX`，按 ArcGIS 安装窗口提示安装。
2. 打开 `离线测试项目/打开这个测试项目.aprx`。如果地图未自动显示，在目录窗格双击“现场操作测试（合成资料）”。
3. 在功能区找到“补充耕地验收”→“采样助手”。首次验证请使用本包资料，项目备案编号留空。
4. 记录 Pro 完整版本、操作人及耗时。先双击离线自检，再完成下列四步界面操作。

## 四步操作示意

**① 选资料 → ② 自动准备 → ③ 预览确认 → ④ 导出成果**

**选资料：**选“合成测试图斑”；处理范围选全部。点击“使用当前地图影像”，选择“合成测试影像”。也可扫描资料文件夹，再按完整路径选择。不要选其他历史演示成果。

**自动准备：**填写真实的制图单位，选择一个新建空成果目录，点击“自动准备并加载地图预览”。预期为 2 个候选单元、至少 6 个混合样设计点、每单元 3 个容重平行候选点。缺少系统项目编号时保留候选编号。

**预览确认：**使用编号定位查看各单元；填写修改人，选择设计点编号，点击“在地图点选位置并吸附”，再点击该图斑内其他网格候选位置。成功后会复检、同步新 SHP/CSV 并重新加载预览。附近无空闲候选点时应提示拒绝。

**导出成果：**核对单元、点位及影像，填写设计确认人并勾选确认，再点击“确认设计并导出图件”。正常得到位置图、采样布置总图及逐单元补图的 JPG、PNG、PDF；每幅附检查与缩略图。来源精度等待核项应继续显示，不能写成正式验收通过。

## 还要验证的情况

- 更换成果目录后，原任务点号应清空；不能在查看任务 A 时误修改任务 B。
- 取消后再次准备，应复用已完成阶段；损坏或删除一张 JPG 后继续，应重建损坏图件。
- 修改影像或单元/点位后，旧确认不能直接导出；需重新准备并确认。
- 逐单元选择不同 DOM 后重新准备，逐图来源清单应分别记录；总览为混合来源。
- 指北针/单位缺失、查询失败或损坏影像应报失败；低纹理只列疑点。

## 回传哪些结果

填写 `现场验收记录.csv`。失败时保留整个成果目录，提供软件版本、最后操作、错误文字或截图、`task_state.json`、`一键成果报告.json` 和对应检查报告。不必修改程序文件。

## 本候选版的边界

本包交付采样设计和外业准备能力。合成 DOM 只能证明操作链路，不能证明真实影像清晰度或位置精度。正式项目需提供真实 DOM、坐标及时相和精度依据；系统项目编号由操作者从系统核对，不得自编。

另一电脑、新手操作及本机完整侧栏点击链路仍需现场验收。本机自动化窗口捕获/点击失败，未把界面实操记为通过。版面压盖的完整自动判定、影像精度证明的专门审核界面、候选来源缩略图等后续项见实施记录。
