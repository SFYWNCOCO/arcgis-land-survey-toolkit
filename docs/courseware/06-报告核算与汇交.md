# 模块 6 · 报告、核算与汇交

对应官方课件：p61–63（鉴定意见、初鉴报告、数据库）、p72–92（核算、汇交）。

## 学习目标

- 会出鉴定意见表与初鉴报告底稿，知道哪些不能自动填。
- 会算三口径平均等级并解释结论。
- 会按附录 I 目录做交付清单，知道哪些必须人工复核。

## 报告与表单

- 鉴定意见表：一个评价单元一张；工具预填单元、项目、位置，结论/等级/签字留人工。
- 县级初鉴报告：按附录 L 章节；工具填表 1（符合性）与表 2（等级/平均等级），正文说明保留模板提示。
- 生成依据：参数版本、计算时间、输入路径、UNVERIFIED/待补清单必须写进底稿。
- 没有实测/检测/评价依据，正文不得出现等级数字；教学演算与项目正文物理分离。

## 三口径核算

- 公式：平均等级 = Σ(等级×面积) ÷ Σ面积，以县域为单元。
- 三类分开：各类占用、非农建设占用、补充耕地。
- 占用等级取整数（三普成果/耕地质量等级数据库）；补充等级取两位小数（市级鉴定意见）。
- 补充 ≥ 非农建设占用 → 可按程序报备；补充 < 各类占用 → 须培肥改良，5 年内再评价。
- 指导书 §7.2.4 示例有印刷陷阱：公式最后一项误印 5.57，应为 7.52；用明细复算。

## 操作步骤

1. 在 `project.json` 加 `accounting`，运行 `evaluate_acceptance.py`。
2. 读 `核算`：三口径平均值、结论、明细。
3. 跑 `python scripts/delivery_package.py --check --root <项目目录> --html`。
4. 看 `交付清单.html` 与 `delivery_check_report.json`：缺文件、待人工复核项。
5. 人工完成：签字盖章、CMA 能力范围、照片真实性、报告正文、专家意见。

## 汇交目录（附录 I）

- 数据库成果：项目编号.gdb（DLTB 不改 + 附录 G 评价单元图）。
- 图件成果：地理位置图.jpg、采样点位布置图.jpg。
- 文字成果：鉴定意见表.pdf、县级初鉴报告/市级报告与意见（按层级）。
- 附件：鉴定函、申请表、踏勘表、采样记录表、检测报告、专家意见、举证照片。

## 常见错误

- 把“文件存在”当“内容合格”：交付清单只做结构检查，内容仍须人审。
- 报告、图件、数据库、附件四处编号不一致：逐项交叉核对。
- 市级报告直接复制县级结论：必须写差异与复检情况。
- 汇交前没导 PDF：正式件按接收方要求转换并逐页复核。
