# 补充耕地质量鉴定工具培训 · 课程总览

## 适用对象

- 第一次接触 ArcGIS Pro 的县级/第三方采样、内业人员。
- 需要把「资料接收 → 单元划分 → 布点 → 外业 → 评价 → 核算 → 汇交」走完的项目负责人。

## 先决条件

- ArcGIS Pro 3.1.x，已安装「补充耕地验收」插件。
- 项目图斑（FileGDB/Shapefile）与移交资料；没有的资料不得推测。
- 项目参数：系统验收备案编号（15 位）、县/镇/村、项目名称、编制单位。

## 六个模块与官方课件对应

| 模块 | 内容 | 官方课件页 |
|---|---|---|
| 1 | 资料接收与体检 | 21–26 |
| 2 | 评价单元划分与字段映射 | 31–32 |
| 3 | 网格布点与外业准备 | 33–34、45–50 |
| 4 | 表格、标签与照片要求 | 34、47–51 |
| 5 | 符合性评价与等级评价 | 54–60 |
| 6 | 报告、核算与汇交 | 61–63、72–92 |

## 工具边界（必须讲清）

- 工具只出**设计候选**与**技术检查结论**，不替代现场采样、检测、专家审核、签字和 CMA 能力核验。
- 状态只有 `PASS / FAIL / NEEDS_REVIEW / UNVERIFIED`；未知项不得写成通过。
- 0.2 m 项目 DOM、正式县界、系统备案编号属于外部资料缺口，缺了就标待补，不编造。

## 学完能做到

1. 用面板把图斑、编号字段、四因素资料和项目参数配好，保存复用。
2. 一键生成评价单元、四套网格成果、两张报件图、附录 D/E/F 表与样品标签。
3. 带齐「2 图 2 表 2 标签」去外业，回传后跑符合性评价、等级评价和三口径核算。
4. 按附录 I 目录检查交付包，知道哪些必须人工签字/复核。
