# 模块 1 · 资料接收与体检

对应官方课件：p21–26（资料移交、审核、图斑合规性）。

## 学习目标

- 知道一个项目最少要收哪些资料。
- 用「检查资料」在 1 分钟内发现：坐标系、编号字段、四因素、项目编号、成果目录、表格模板的问题。

## 资料清单（收齐再开工）

- [ ] 补充耕地质量鉴定图斑（GDB/SHP，附录 C 字段）
- [ ] 补充耕地国土变更图斑 DLTB（不改动）
- [ ] 鉴定函、鉴定申请表、土壤污染检测报告（适用时）
- [ ] 项目设计/竣工报告、批复、图纸（项目类）
- [ ] 0.2 m 项目 DOM 或无人机正射；没有则只能出自查图
- [ ] 居民点/道路/水系/境界线资料（有则放同目录 `地理要素.json`）
- [ ] 系统验收备案项目编号（15 位，不得自编）

## 操作步骤

1. 打开 ArcGIS Pro，加载补充耕地图斑。
2. 打开「补充耕地验收」→「采样助手」。
3. 点「刷新图层与选择范围」，选图斑图层。
4. 在「图斑编号字段」下拉确认编号列；自动识别错误时手动选。
5. 需要四因素面资料时，展开「辅助资料角色」逐项选择土种/地形部位/来源/利用现状。
6. 填项目名称、县/镇/村、项目编号、编制单位。
7. 点「保存项目参数…」，下次同区域项目点「加载项目参数…」复用。
8. 点「检查资料」，逐条看 `PASS / FAIL / NEEDS_REVIEW`。

## 检查项怎么读

| 结果 | 含义 | 下一步 |
|---|---|---|
| PASS | 该项满足 | 无需处理 |
| FAIL | 硬失败，继续会出错或不能报件 | 按提示修正后重跑 |
| NEEDS_REVIEW | 缺资料或需人工判断 | 补资料/留依据，不得当通过 |
| UNVERIFIED | 未取得数据/未实测 | 报告里写“待核” |

## 常见错误

- 把 `PURPOSE=开垦` 直接当“补充耕地来源”：来源只认“恢复/垦造”，缺字段就保留候选。
- 项目编号自编：15 位编号必须来自广西占补平衡动态监管系统。
- 成果目录不是空目录：新任务会被拒绝；继续旧任务用「继续上次任务」。
- 没有 0.2 m DOM 却把在线影像当报备底图：只能自查，不能进正式成果。
