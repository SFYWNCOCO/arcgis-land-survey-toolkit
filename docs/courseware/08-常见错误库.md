# 常见错误库（工具侧）

> 每条：现象 → 原因 → 处置。来自实测记录与 corrections，不收录未复现的猜测。

## 报错/现象类

| 现象 | 原因 | 处置 |
|---|---|---|
| 出图整片灰白 | 在线影像返回 z19 占位瓦片 | 工具已按 md5/灰度识别并回退层级；仍灰白就换项目 DOM |
| 图例出现 Band_1/2/3 | 图例自动添加栅格项 | 工具用 Layout CIM 冻结图例；不要手工再加服务图层 |
| 北坐标整列消失/NaN | 逐属性改 CIM 文本触发 NaN | 用 CIM 一次性写 text/shape/visible；已修复 |
| 图廓注记压线 | 模板锚点跨内外图框 | 用最新模板；按深审记录坐标 |
| 网格交点沿边界密密麻麻 | 从裁剪多边形顶点取交点 | 改为规则格网角点；工具已修复 |
| 同一 .aprx 保存报 OSError | 进程内开了两个 ArcGISProject | 建工程与导出拆两个进程；不要手工并行开 |
| 目录非空无法新任务 | 成果目录已有文件 | 换新空目录；继续旧任务点「继续上次任务」 |
| 模板出现“XX县/×××” | 静态占位 | 填 meta；未填显示（待填），`check_map_elements.py` 会判 FAIL |
| 表格生成报缺 python-docx | Pro Python 未装 python-docx | 工具包已内置 vendor；不要改 Pro 环境 |
| 区域/县不匹配 | 县选错农业区 | `region_guard` 会停；按附录 J 重选 |

## 口径类

| 现象 | 原因 | 处置 |
|---|---|---|
| 50 亩判错对象 | 把单元上限套到图斑 | 约束对象是评价单元；单图斑超限要拆成多单元 |
| 把 1–5 级当质量等级 | 监测分级 ≠ 验收等级 | 验收用权重×隶属度→综合指数→10 等 |
| 权重和不为 1 仍计算 | 指标错选/漏选 | 先查指标集；不得归一化掩盖 |
| 补充等级用了县级值 | 核算要求市级鉴定意见 | 只用市级；县级仅作过程 |
| 两位小数等级直接用于正式报告 | 插值式待核 | 当前标 UNVERIFIED；先与三普规范附录 J 核对 |
| 设计点当实采点 | 证据链混淆 | 设计点只作候选；实采坐标/照片/样品号另建证据 |

## 外业类

| 现象 | 原因 | 处置 |
|---|---|---|
| 容重 3 个平行样只贴 1 张标签 | 未按平行样分袋 | 每袋一张标签，勾选 1/2/3 |
| 照片只有景观照 | 漏拍剖面/四分法/容重/侵入体 | 按模块 4 清单逐点补拍 |
| 表格签字栏空 | 未完成三方签字 | 踏勘/采样至少两人，专家按课件要求签字 |
| 检测顺序颠倒 | 先检等级指标 | 先符合性（有机质/pH/重金属），合格后再检等级指标 |
