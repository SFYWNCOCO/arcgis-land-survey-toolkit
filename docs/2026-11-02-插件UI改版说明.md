# 插件 UI 改版说明（2026-11-02）

> 范围：`land_survey_toolkit` 的 C# 侧栏 UI（ArcGIS Pro 3.1.5 插件，`net6.0-windows`，全部用代码构建、无 XAML）。
> 目标：在不改业务逻辑与执行链路的前提下，重做工作台外壳、采样面板、AI 侧栏与两个弹窗，做成贴近桌面软件原生观感的专业工具界面（克制、扁平、信息密度高），而不是通用聊天式/AI 风格。
> 配套调研：`docs/2026-11-02-AI控制绘图与插件UI调研.md`（外部项目如何接 AI 控制图层/绘图，以及本项目差距与路线）。
> 独立审核：`temp/ui-review-20261102/review.md`、`delta-review.md`、`final-review.md`（含 round-4/round-5 差量确认）。
> 离线渲染图：`docs/ui-preview/`（浅色/深色各两张，由 `temp/ui-preview/build_preview.py` 渲染）。

---

## 0. 结论

- 新增视觉层 2 个文件（`UiTheme.cs`、`UiComponents.cs`）：颜色/字体/圆角/控件密度收口为 token 与隐式样式；6 个 UI 文件不再各写默认控件。
- 结构改版 6 个文件：工作台外壳（扁平标题条 + 下划线页签）、采样面板（分区细线、扁平折叠区、单一主按钮）、AI 侧栏（指令引述块 + 纯文本回答 + 工具执行行 + 输入区）、地块定位窗口、高德密钥窗口、图斑编辑面板。
- 独立审核共 5 轮：第一轮提出 3 个阻塞与 10 类应修并全部修复；后续轮次结论均为“可交付（无阻塞）”，终审提出的 5 条低风险应修与 round-4 残留 2 条微调已在终稿前处理。
- 按“减少 AI 味”做设计收敛：去掉渐变品牌区、聊天气泡、✦ 装饰图标、全屏圆角卡片、投影与多色强调；改为扁平标题、下划线页签、细分隔线、单一深青色强调、规则标签。
- 仍未做：真实 Pro 内人工点击验收、运行期主题切换/高对比度、Ribbon 图标与按钮命名、面板内联间距的彻底 token 化。

## 1. 设计决定（token）

| 维度 | 取值 | 说明 |
|---|---|---|
| 主题 | 浅色 / 深色自动切换 | 反射读 `FrameworkApplication.ApplicationTheme`；离线用 `ACCEPTANCE_UI_THEME` 强制；运行期切换需重开侧栏 |
| 底色 | 浅 `#F3F4F6` / 深 `#1C1E21` | 面板底 |
| 卡面/分隔 | 面 `#FFFFFF` / `#25272B`；细线 `#DFE3E6` / `#383B40` | 以细线和留白分组，不再满屏圆角卡片 |
| 主色 | 浅 `#0F5F4C` / 深 `#3FAF8E`；主按钮填充 浅 `#0F5F4C` / 深 `#1E6E58` | 深青绿；只用于主按钮、焦点、选中页签、分区细条 |
| 文字 | 主 `#1F2328` / 次 `#4B5563` / 弱 `#667085`（深色 `#E8EAED`/`#B0B5BC`/`#8A9099`） | 弱文字对比度 ≥4.5:1；深色主按钮文字对比度 5.81:1 |
| 字阶 | 13.5（标题）/ 11.5（正文、按钮、输入）/ 10.5（说明）/ 10（小字、版本）/ 9.5（角色标签） | 中文优先 `Microsoft YaHei UI`，回退 `Segoe UI` |
| 圆角 | 卡片/弹窗 8、输入/按钮 5、标签 3 | 收敛到两档半，不再大圆角胶囊 |
| 控件密度 | 按钮高 28、输入高 28、页签下划线 2px | 460px 侧栏可容纳更多有效信息 |
| 语义色 | 成功 `#1B6E45`、警告 `#8A5A00`、危险 `#B42318`、信息 `#1F5AA6` | 状态点、标签、状态文字共用；停止/取消/跳过保持中性色 |

## 2. 新增组件与样式

`addin/AcceptanceAddin/UiTheme.cs`
- 主题检测（反射，不依赖 Pro SDK；失败回退浅色）。
- 隐式样式：`Button`、`TextBox`、`PasswordBox`、`ComboBox`/`ComboBoxItem`（含可编辑模式）、`CheckBox`、`Expander`（扁平细线头 + 可键盘聚焦）、`ScrollBar`、`ToolTip`、`ListBoxItem`、`ListView`/`ListViewItem`/`GridViewColumnHeader`、`TabControl`/`TabItem`（下划线页签）。
- 关键按钮样式：主按钮（深青实底）、安静按钮、危险按钮、标签 chip。
- `ToneOf` / `ToneStatus` / `WatchStatus`：状态文案分级着色（失败红、待办橙、成功绿、其它中性；停止/取消/跳过保持中性），兼容现有 100+ 处 `_status.Text=`。
- `FlattenNestedExpanders`：嵌套折叠区统一为扁平样式。
- 模板解析失败自动退回系统默认样式（`Trace` 记录），保证侧栏不会因样式问题打不开。
- `Space` 间距刻度（组件内使用；旧面板内联值待分批收敛）。

`addin/AcceptanceAddin/UiComponents.cs`
- `UiKit.PageHeader`（扁平标题 + 说明 + 版本，底部细线）。
- `Card / Surface / FooterBar / Section / Divider / Pill / Dot / Chip / EmptyState`。
- `Bubble`（用户指令：整行引述块）/ `AssistantBubble`（纯文本回答 + 角色标签）/ `SystemNote` / `SelectableNote`（可复制）。
- `ToolCard` / `SetPhase`：工具执行行（状态点 + 名称 + 阶段，底部细线）。
- `UiConfirmWindow.Ask`：风格化确认弹窗，替代系统 `MessageBox`（AI 地图操作、删除密钥）。

### “减少 AI 味”的设计收敛

- 删除渐变品牌区、圆角 14 大卡与投影，改为扁平标题条 + 细线。
- 删除聊天气泡与 ✦ 图标，改为“你/助手”角色行 + 整行引述块。
- 页签从灰底胶囊改为下划线式，符合桌面软件习惯。
- 卡片样式的折叠区改为细线分隔的扁平分组，信息密度更高。
- 强调色只保留给主操作、焦点与选中态；状态色降低饱和度。

## 6. 与调研结论的衔接

调研指出“AI 控制绘图”的真正短板是：零几何写入工具、图斑编辑候选机制 AI 不可调、无撤销栈、无图像回读、MCP 侧写工具无人工确认。本轮先把“人看得懂 / 人收得回”的前两层做了：工具执行行、状态语义、空态引导、写操作统一确认弹窗、可复制的回执原文。仍属下一步（未实现）：AI 生成图斑候选并预览/确认、图像回读给模型、撤销栈、MCP 两段式确认。

## 7. 未验证与已知限制

- **未在真实 ArcGIS Pro 界面点击验收**：可编译、可离线渲染、可打包，但未启动 Pro 加载新包实测；深色主题实际观感、输入法组合键、可编辑下拉框、模态确认窗在 Pro 主窗口的置顶/焦点、460 宽 × 700/768 高布局仍需人工过一遍。
- **主题判定是尽力而为**：依赖 `ApplicationTheme` 反射读取，取值结构未在 Pro 内验证；运行期切换主题需重开侧栏。
- **Pro 套件 1 项失败为既有问题**（见 §4），非本轮引入，需业务侧定位。
- **Ribbon 未改**：22 个按钮无图标、2 个工具只能由代码触发、“一键出图”名实不符（审计 A18–A24）。
- 离线渲染图是设计效果示意，不是 Pro 内实拍截图。
