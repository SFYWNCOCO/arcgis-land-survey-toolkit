- 在途模型请求可能恢复被清空的历史：加入服务/模型/密钥指纹与清空代次，独立 HTTP 探针确认修复；请求期间禁用服务预设。
- “测试连接”不应执行地图工具：独立无历史请求，软件层禁止工具；异常模型请求工具也被拒绝。
- GP 取消请求位不能代表最终结果：改用 IGPResult.IsCanceled/IsFailed，另报 cancel_requested。
- MapView 导出 DPI/尺寸会裁切边缘点：按视图尺寸与目标像素/DPI调整导出相机，三点回归先失败后通过。
- DockPane 放在 controls 内可编译却不注册：改入 dockPanes，新增结构契约并用真实 Pro 打开侧栏读回。

执行者之外的独立审查者重跑了核心测试、stdio 握手、包内容比对，并独立复现/复核会话历史问题。

共享工作区作用域检查使用任务开始前的内容基线。检查仅报告 `config/proposal_scopes.json` 越界：它正是本任务调用 declare 时由检查器写入的登记文件；没有为获得绿灯而事后扩大白名单。该辅助检查未通过，产品测试和包验证的结果单独列示。产品源码仅新增于 `ARCGIS/pro_ai_bridge/`；另有已授权的 DSH 桌面 profile 追加配置。

## 明确的覆盖限制

- DSH 的 MCP 客户端路径是真实模型测试；Pro 内 Chat Completions 兼容层完成了真实 HTTP 模拟服务测试，尚未逐家使用商用 API Key 实测。
- 桌面截图持续超时，未完成按钮逐一点击的图形交互验收；侧栏真实注册、创建和可访问性控件清单已确认。
- 仅实测 Pro 3.1.5；未验证 Pro 3.3+、三维场景、所有数据源及所有 GP 工具/许可。运行中大型 GP 的主动取消尚未专门覆盖。
- “取消”不撤销已完成的 GIS 修改；模型输出的正确性也不由协议通过保证。

Pro 调用明细见 `pro-live-receipt.json`，构建哈希见 `../dist/build-receipt.json`。
