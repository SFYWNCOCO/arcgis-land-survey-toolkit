# Pro AI Bridge 0.2 易用性实施计划

**Goal:** 在已有地图工具上增加可观察、可选择的连接与任务体验，减少手工配置和查询。

**Architecture:** MCP 会话独立保存目标进程/工程选择；管道请求携带工程身份，由 Pro 执行器在操作前校验。侧栏继续操作所在 Pro 窗口，显示本窗口工程、连接诊断、自动任务列表与导出文件按钮。原地图执行器和模型 API 循环继续复用。

**Tech Stack:** Pro SDK 3.1 / .NET 6 / WPF / MCP SDK 1.x / Python 3.12。

用户已批准易用性升级及自主开发测试。本轮不增加分析/制图算法。共享树保留原位置，不迁移其他任务文件，不改变 DSH 模型和授权策略。旧版安装包保留用于回退，源实现原位升级。

## 任务一：MCP 工程发现和选择

- 修改 `mcp_server.py`、`tools.json`、`addin/Bridge.cs`、`addin/MapActions.cs`、`addin/ToolProtocol.cs`。
- 先在 `tests/test_mcp_server.py` 添加多进程发现、显式选择、失联/切换工程拒绝、环境 PID 兼容测试，观察失败，再实现。
- 加入本地诊断入口 `--diagnose`，输出 Pro 会话、DSH 配置/进程的明确状态，不读取模型密钥、不发起模型请求。
- 加入 `list_pro_sessions`/`select_pro_session`，原来仅一个 Pro 时仍可直接使用。显式选择绑定工程身份，目标工程变化时拒绝执行并要求重选。
- 这两项为 MCP 客户端连接工具，侧栏模型不提供它们，避免误认为可以从当前 Pro 侧栏控制另一窗口。

## 任务二：任务/导出 UI 状态

- 新增 `addin/PaneState.cs`，只承接不依赖 Pro 的任务状态合并、导出路径验证与项目身份校验；供实际侧栏及 C# harness 共用。
- 修改 `tests/CoreHarness.cs`、`tests/test_core.py`、`build.py`，先用真实 C# 执行测试自动刷新单次并发、未变化不重复提示、结束保留结果、只接受已成功导出的文档路径等契约。
- 在 MapActions 增加 `list_jobs`，侧栏定时读取任务列表，展示状态、消息和取消请求；项目发生变化时清空聊天历史及当前输出。
- 导出按钮只打开实际导出收据中的现存 PNG/PDF；文件夹通过系统文件管理器打开，不执行任意文件。

## 任务三：连接诊断与侧栏布局

- 修改 `addin/ChatPane.cs`：当前工程常显，新增一键连接检查，任务列表自动刷新，导出文件/所在目录按钮在成功后启用。
- 新增诊断纯逻辑在 `PaneState.cs` 中；DSH“未运行/已运行”“未配置/已保存”分开，不能仅凭配置文件就声明已连接。
- 保留模型连接测试的无工具约束、密钥保护、危险操作确认和取消边界。

## 任务四：验证、审查与交付

- 版本统一为0.2.0，修改既有构建与安装脚本使用DAML版本，不另建平行实现。
- 跑C#核心、MCP、stdio与包契约测试，再用新的合成工程跑真实Pro；验证目标选择、任务轮询、PNG/PDF和侧栏控件。
- 用当前DSH运行时的既有账户完成模型→MCP→Pro查询，并尝试真实桌面加载和按钮交互；受宿主限制时明确记录覆盖缺口，不伪报通过。
- 按 requesting-code-review 技能进行独立审查，修复重要发现。
- 更新README、测试报告与收据，生成0.2安装包/完整源码包，读回包内容和安装哈希。此前临时文件清理被宿主拒绝，不绕过该拒绝。

验证命令：`py -3.12 build.py --harness`、`py -3.12 -m pytest tests -q`、`py -3.12 build.py`、`py -3.12 build.py --bundle`（在本目录）。真实测试仅指向新建合成工程。
