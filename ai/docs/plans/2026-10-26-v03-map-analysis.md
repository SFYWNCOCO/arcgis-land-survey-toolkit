用户已批准立即实施。沿用既有桥接、模型客户端和 GP 任务执行器，保留 0.2 安装包供回退。

1. 先为地图上下文、同级图层排序、分析参数添加失败测试，再实现。新增 `AnalysisPlan.cs` 承担不依赖 Pro 的分析参数校验，实际由 MapActions 调用，并纳入现有 C# harness；不另设执行器。

3. 请求增加可选地图身份；MCP 绑定工程和地图，切换后显式更新。侧栏跟随当前地图，在上下文变化时清除旧对话，避免同名图层误操作。
4. 增补真实 Pro 合成工程，检验两张地图、图层操作、输出数据及错误拒绝；用现有 DSH 账户做 MCP 联调。尝试侧栏交互，宿主未支持的点击或截图如实记为未验证。
5. 更新为 0.3.0，独立代码审查后修正；更新既有说明、测试报告和收据，生成并安装新版。读回包内容与安装哈希。旧版及此前删除被拒的临时文件保留，不绕过删除限制。

修改范围为此项目与前置 scope 声明。验证按纯逻辑/契约测试 → 原生编译 → 新合成工程真实执行 → DSH → 包/安装读回进行。跨模块上下文是主要风险；失败时保留旧安装包，修正前不发布新版。
