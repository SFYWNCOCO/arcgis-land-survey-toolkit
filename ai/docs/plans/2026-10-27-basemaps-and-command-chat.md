# 多来源底图与命令式交互实施计划

目标：在现有 Pro 侧栏提供官方高德矢量/卫星预览、天地图影像/矢量预览和独立底图凭证配置；采样影像管线接纳明确声明坐标系的授权 XYZ/WMTS。交互采用连续对话、斜杠命令、输入历史、可展开工具收据。

用户已授权自主优化和开发；没有高德密钥或阿里云服务地址。离线接口与本机测试可完成，真实提供商取图必须标为待配置。预览不会写回业务地块。

1. 先增加失败测试：命令解析、预览参数/凭证验证、加密存取、本机 HTTP 页面隔离、授权服务坐标声明与 WMTS 模板。
2. 在 PaneState.cs 复用状态验证职责；新增 BasemapPreview.cs，因为服务凭证及浏览器预览有独立生命周期，MapActions 只负责调用。加入两项 MCP 工具，不把密钥纳入工具参数或返回。
3. ChatPane.cs 复用现有模型与任务执行器，改连续卡片、折叠工具记录、斜杠菜单、回车发送/Shift+Enter 换行、空输入上/下历史。原任务取消、结果加载和工程守卫保留。
4. imagery.py 沿用现有瓦片下载/覆盖检查，增加天地图图层与标准 Web Mercator WMTS 模板；自定义配置必须声明 EPSG:3857，拒绝 GCJ-02/未知基准。不建立旧数据兼容分支。采样助手的授权来源标签与模板同步。
5. 编译 C# 核心与插件、运行相邻 Python/C# 契约及本机 HTTP 测试。使用合成 Pro 工程测试 MCP。若业务 Pro 正在运行，仅交付包，不能强关。
6. 独立审查后修复；检查包内源码/目录/哈希，更新使用说明与真实限制，安装需核对进程和安装后哈希。已有 21 点成果及项目参数不修改。

风险与恢复：高德 GCJ-02 仅通过官方 SDK 转换初始 WGS84 定位供预览，不伪标 CGCS2000；本机预览服务只绑定回环、随机令牌 URL、禁缓存、无文件密钥、关闭 Pro 即释放。密钥 Windows 当前用户加密保存，可清除重新配置。保留既有安装包用于恢复；共享 Git 改动不提交/重置。

官方依据：高德 https://lbs.amap.com/api/javascript-api-v2/guide/layers/official-layers 、安全密钥 https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode 、天地图 https://lbs.tianditu.gov.cn/server/MapService.html 。阿里云没有用户具体服务，通用模板待填写，不宣称已在线联通。
