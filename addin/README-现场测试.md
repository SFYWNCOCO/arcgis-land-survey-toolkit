# 采样助手 1.49 完整测试包

本包用于 ArcGIS Pro 3.1.x 本机和现场联调，包含 Add-In、离线/实时 MCP 运行文件及路径隔离测试；不含地块、项目或演示数据。请先复制一份测试工程，勿直接拿正式项目做首次测试。

1.46 基线在 ArcGIS Pro 3.1.5 / Python 3.9.16 全量回归 495 项通过、3 项跳过，另有无影像出图集成用例 1 项通过。1.49 的 Python 3.12.10 全量回归 451 项通过、8 项跳过；Add-In 界面契约测试 15 项、定位行为测试 4 项（27 项断言）通过，Roslyn 安装包核验60项。1.49 固定操作区和地块定位窗口仍需在 ArcGIS Pro 中点击验收。

## 安装与 MCP 检查

1. 解压完整 ZIP，保留目录结构；双击 `AddIn/SupplementaryCultivatedLandAcceptance_1.49_*.esriAddInX` 安装后重启 ArcGIS Pro。
2. 在 MCP 客户端配置 `MCPRuntime/arcgis_mcp/server.py`（离线工具）和 `MCPRuntime/arcgis_mcp/live_server.py`（当前 Pro 地图工具），重启 MCP 客户端。
3. 查看工具清单，实时服务应列出 `live_status`、`live_list_layers`、`live_search_parcel` 和 `live_zoom_to_parcel`。如果 `live_status` 返回 Win32 2，表示命名管道未启动；检查 Add-In 版本并完全重启 Pro。侧车工具清单可用不等于 Pro 已连接。
4. 调用 `workspace_status()`，确认只读 `read_roots` 和可写 `write_roots`。其他电脑按本机路径设置 `ARCGIS_MCP_READ_ROOTS`、`ARCGIS_MCP_WRITE_ROOTS`，分号分隔；旧 `ARCGIS_MCP_ROOTS` 仅授权读取。
5. 运行 `run_tests(paths=["tests/test_mcp_server.py", "tests/test_live_mcp_server.py"], allow_write=True)`，确认离线路径隔离与实时 MCP 请求校验通过；Pro 自带 Python 环境需安装 pytest。这些自动测试不要求实时管道已经连通。

## 固定操作区可见性检查

1. 缩小 ArcGIS Pro 侧栏高度并滚动四步内容，确认侧栏底部持续显示当前运行状态和“确认设计并导出图件”。
2. 确认“继续上次任务”“取消”“打开成果文件夹”和“打开本次运行摘要”仍可在固定操作区找到；运行日志默认折叠，展开后可阅读详细消息。
3. 点击验收前先使用测试工程；仅确认按钮可见和可点不代表真实导出已经通过。

## 地块定位器检查

1. 从采样助手打开地块定位窗口，选择“全部面图层”；字段列表应显示可搜索编号字段及其覆盖图层数，例如“DKBH（2/4个图层）”。
2. 选择一项非标准业务编号字段，按已知编号检索；检查结果来源路径和编号，确认定位到正确图形。字段大小写不同的图层也应能检索；对不含该字段的图层，确认它被跳过并列出提示，不能用该层默认字段误搜。
3. 切换到单个图层，确认字段列表只显示该层字段；“对象ID（技术定位）”仅在单层选择时出现，不能冒充业务地块编号。
4. 选中地图中的要素后启用“仅检索执行时选中的要素”，再加载图层；上一块/下一块只能在本次结果清单内翻查，不跨图层。

## 采样坐标与地面间距

- 网格采样要求可确认的 CGCS2000 三度高斯—克吕格米制坐标系。工具读取坐标系参数并核对中央经线、带号/假东距；经纬度、Web Mercator、UTM、六度带及参数不一致的坐标系会在建成果前拒绝。
- 输入应依据项目测量资料先投影到正确的三度带。工具不替用户猜测坐标转换或带号。
- 15 米间距由 ArcPy `GEODESIC` 地面距离检查；结果报告包含坐标系核验信息。小图斑产生的不足间距仍须按指导书要求人工核实，不自动豁免。

## 影像来源与精度证明

- 项目 DOM 可通过旁置的 `.source.json` 记录 `source_gsd_evidence` / `source_gsd_review` 及 `positional_accuracy.evidence` / `positional_accuracy.review`。证明文件须是本机可读且非空的文件；插件计算 SHA-256，并在报备检查时复核文件未变化。
- 人工审核记录须为 `status=VERIFIED`，并提供审核人 `reviewer` 和日期 `reviewed_at`。位置精度值须为有限正数且严格小于 0.2 m，才满足该系统报备门槛。
- 插件核对文件、哈希和审核记录完整性，不解析 PDF 内容，也不替专业人员判定证明结论。缺证明、审核记录不完整或文件被修改时，结果保持待复核。
- 下载像元大小、在线服务层级和出图 DPI 不构成位置精度证明。

## 快速现场验收

1. 先在测试工程调用 `live_status()`、`live_list_layers()` 和 `live_search_parcel(query="39")`，核对地图、业务编号和候选图层。
2. 若项目点位层使用旧字段 `CYDBH`，也搜索一个实际点号，确认定位器能跳转到对应采样点；地块号仍按业务字段匹配。
3. 只有确认缩放后果后才调用 `live_zoom_to_parcel(..., confirm=True)`；记录搜索对象、当前范围与缩放结果。
4. 无影像场景下，候选图层可用于内部预览；出图收据必须为 `PREVIEW_ONLY` / `FAIL`，图面需标“无影像预览”，向导不应放行正式导出。补齐合规影像后重新准备、确认并导出。
5. 在隔离测试目录运行网格采样，确认错 CRS 在输出前被拦截；对正确三度带核对设计点数、每图斑覆盖和地面间距报告。
6. 运行出图恢复场景：正常导出后损坏一幅 JPG，再继续任务。应只重出该幅，修复后收据不得把该幅标记为“复用”。
7. 核对中文路径、影像覆盖、图层查询、JPG/PNG/PDF 重开和人工审核项；保存每幅缩略图及现场验收记录。
