## 工作台稳定性改造 1.76（2026-11-01，候选）

采样页、AI/MCP 发起的 GIS 处理及设计点调整共用一个任务占用控制；忙碌时提示当前任务，不自动排队。固定底栏显示当前阶段，运行日志默认折叠；展开后可运行“环境检查”或“复制诊断”。检查实际 GP Python、随包资源和输出权限，离线 DOM 不要求在线密钥。

“停止”立即登记请求，在安全阶段结束后保留进度；启动早期请求也会在本次状态建立后生效。再次打开工作台只恢复最近任务引用，核对来源和参数后点击继续，不自动重跑。预览或导出前仍需检查当前选择集、坐标系和人工设计确认。

成果按钮依据本次运行标识、输入指纹、设计修订及实际文件启用；缺失、空文件、损坏报告和旧报告均不能表示成功。技术处理、AI图面检查和业务审核分别记录；AI图面失败仍保留交付门槛，原始GSD、定位精度与现场事实需专业人员核实。

本轮验证和真实限制见 [验证记录](verification/verification-record.md)。候选包以 `dist/build-receipt.json` 为准，目标环境为 Pro 3.1.5 / .NET 6 / Python 3.9.16。

## POI参考检索 1.58（2026-10-27）

新增“POI参考”功能区：先用“配置高德Key”保存 Web 服务 API Key，再运行“POI参考检索”，选择项目范围面并填写关键词或高德 POI 类型码。在线查询会向高德发送范围包络坐标、关键词/类型码和 Key；原始面几何仅在本机精确筛选。插件按包络请求，之后按原面边界筛选、去重，输出独立 FileGDB 点图层并保留原始 GCJ-02 坐标、来源、查询时间和范围坐标系。成果图层显式标记“仅供位置参考”。

密钥以 Windows 当前用户 DPAPI 加密保存在 `%LOCALAPPDATA%/SamplingAssistant/credentials/amap_poi.key.dpapi`，不进入地理处理参数、输出字段或日志。输入范围必须有已知坐标系；非 WGS84 范围需从 ArcGIS 列表明确选择到 WGS84 的基准转换。POI 坐标由 GCJ-02 近似反算到 WGS84 后建点，位置不能用于测绘、抽样定位、验收或报件；类型码/关键词的 API 配额和使用条件以[高德 POI 2.0 文档](https://developer.amap.com/api/webservice/guide/api-advanced/newpoisearch)及其[坐标系说明](https://lbs.amap.com/faq/advisory/others/39838)为准。同一查询最多读取200条，达到上限时 GP 会提示结果可能不完整。尚需在 ArcGIS Pro 3.1 实机验证按钮交互和真实 Key 请求。

## 功能

- 新建项目：按附录 I 建立目录，并按附录 G 建立空的评价单元 FileGDB 图层。国土变更图斑和质量鉴定图斑必须从正式源库原样导入。
- 矢量数据：读取几何类型、要素数及坐标系，复制到新要素类；坐标系未知时停止，目标 WKID 必须根据项目资料确认。
- GeoJSON / Esri JSON：在“复制矢量到工作库”中选 JSON 文件；混合几何按点、线、面拆为多个要素类。RFC 7946 GeoJSON 按 WGS 84 解释；含非标准坐标参考信息时仍须与测量资料核对。
- CAD：DWG/DXF/DGN 转到新建要素数据集；要求明确源 WKID，源 CAD 文件不改写。单位、中央子午线、带号和控制点仍须核对。
- RTK：按用户指定 CSV X/Y/Z 字段创建原坐标点和目标坐标点两个新图层；源/目标 WKID 均需明确。接入清单记录源 CSV SHA-256/大小/修改时间；两个点层写入 `Z_STATUS`、`Z_FIELD`、`VERT_REF`，含 Z 时强制显示垂直基准未核实。必须核对固定解、天线高、坐标轴序、单位、中央子午线、椭球高/正常高和转换参数。
- 混合样候选点：需输入评价单元面，检查图斑与声明单元的包含关系；生成的只是最低点数候选，实际数量需结合图斑面积、地形、补充耕地来源及外业条件由专业人员复核。`SAMPLE_ID` 按附录 E 等于评价单元编号，`POINT_ID` 用于区分点位，并记录 0–20 cm 设计深度。质检核对每单元/图斑最低点数、坐标系和空间归属；点数只纳入有效关联点，小图斑间距不足会生成含现场依据、覆盖/避边确认及审核人日期的待审记录，不由软件批准例外。
- 容重候选点：按 §6.2.4.2–§6.2.4.3(2) 以质地构型调查点生成 3 个相距 2 m、距中心不超过 2 m 的设计点，样品编号使用附录 E 的 `RZ+评价单元编号`，REP_NO 区分平行样，标记 100 cm³ 环刀。
- 评价单元质检：核对附录 G 结构、坐标系及每个评价单元面积。按指导书6.1.3③，所有评价单元面积必须不超过50亩；超限列为失败项，须按同质性规则拆分/重划并复核。
- 汇交检查：核对成果目录和文件类型；鉴定函/申请表、踏勘表、采集记录、检测报告、专家意见等按清单核对存在性。CMA证书/附表、样品交接记录、检测原始记录列为附录I“其他资料/适用性复核”，不作为所有项目的统一硬性缺项；所有材料内容仍须人工审核。
- 县级初鉴报告如同时存在同名 DOC 与 DOCX，自动优先检查 DOCX，并把旧格式并存列为待人工核验；无扩展名同名文件也会单独提示核实/移出。检查器不判断不同文件的内容是否一致。
- 遥感时相筛查（NDVI）：对两期已完成大气/反射率处理、云/阴影掩膜的红光和近红外单波段栅格计算 NDVI 与差值，检查坐标系、像元网格并按评价单元统计有效像元。输出差值 GeoTIFF、统计 CSV 和来源/参数 JSON。用户必须按产品元数据填写日期、来源、比例因子与偏移量并确认云掩膜；结果标记 `NEEDS_FIELD_REVIEW`，只作核查线索。工具不设 NDVI 合格阈值，不自动判地类、土壤质量或验收结论。
- 遥感数据包预检：递归检查常见影像文件、CRF 目录和 FileGDB 栅格数据集，生成中文 CSV/JSON，逐波段记录 NoData，并列出范围、坐标系/WKT、旁置文件和复核标记。单栅格的坐标系定义不代表与其他输入已匹配；配对核验完整 CRS 与栅格网格后，才可开展同 CRS 计算。跨 CRS 投影仍需依据控制资料确认；不自动赋予 EPSG、不改写原始栅格。
- 单期连续专题栅格摘要：要求单波段文件型栅格与唯一编号评价单元的空间参考完全一致，像元须为方形且分析窗口不超过明确的像元预算；按栅格网格中心点统计有效/NoData像元数、有效像元比例、最小值、均值、中位数、标准差和最大值，输出 CSV/JSON 并记录源文件哈希/WKT。暂不投影、不重采样、不支持分类栅格面积统计；覆盖率分母仅为栅格范围内的单元中心像元。结果固定为 `NEEDS_FIELD_REVIEW`，不作为质量等级或验收结论。
- 混合样设计点空间质检：要求图斑面、评价单元面与 `DESIGN_ONLY` 混合样设计点坐标系严格一致且为投影 CRS；按指南核对评价单元编号对应关系、图斑/点位归属、`SAMPLE_ID=评价单元编号`、每评价单元≥3个有效点、每图斑≥1个有效点以及一般15 m间距。无关联或空间外点不计入覆盖数，编号错仍判 `FAIL`。低于15 m会列出距离和未签认的例外证据栏；均匀性、田边避让、代表性、障碍和可达性继续人工复核。
- Sentinel-2目录检索：操作者明确启动后，将AOI转WGS84提交Earth Search；检查分页完整性、L2A资产/比例因子/NoData并按日期/平台/处理基线分组，输出几何足迹覆盖率。需要先确认AOI会发送到公开目录。
- Sentinel-2时相准备：要求同一AOI指纹与人工选择的前后期候选组；跨平台或处理基线须确认。GDAL输出裁切镶嵌的10m Float32 B04/B08与20m UInt16 SCL，再调用NDVI+SCL核心。有效像元覆盖和SCL NoData会分开统计；输出依然是现场核查线索。

## 安装

> `dist/` 与 `_archive/` 为本地构建与历史归档产物，已由 `.gitignore` 排除、不随仓库发布；安装包请从 Releases 获取或按 `README-build.md` 自行构建。
与使用

1. 用 `package.ps1` 编译 `.esriAddInX`；构建说明见 `README-build.md`。新包只写入 `dist/SupplementaryCultivatedLandAcceptance_<版本>_<时间>.esriAddInX`；发布确认后将旧包连同哈希清单归档至 `_archive/`，不让历史版本堆在活动交付目录。
2. `install_addin.ps1` 默认选择发行目录最新的版本化包，也可显式指定 `-PackagePath`。完成实机确认后安装当前用户 Add-In，重启 ArcGIS Pro，在“补充耕地验收”功能区操作。
3. 首先运行“新建项目与数据库”。坐标系 WKID 仅填写测量/项目资料明确的坐标系。
4. 在矢量接入工具中二选一指定要素类或 JSON 文件，再按顺序接入正式图斑/CAD/RTK。输出均为新数据集，发生同名冲突时拒绝覆盖。
5. 采样工具生成的是候选设计点，不是现场实采结果。必须由采样负责人核对点位代表性、网格均匀性、15 m 间距、小地块避边和现场可达性。
6. 处理遥感数据前先用“遥感数据包预检”查看数据类型和坐标信息；WKID=0 但含完整 WKT 时，只有各影像和评价单元采用完全相同的坐标定义才可在该 CRS 内运算。投影到其他 CRS 时须有数据源说明或控制点依据。

## 规则边界

采样引用广西作业指导书 v1.1 第 6.1.1–6.1.4、6.2.4.2–6.2.4.3；交付目录引用第 10.1–10.4、附录 C/G/I。混合样每评价单元至少 3 个分样点、每图斑至少 1 点，一般间距不小于 15 m；容重样是每单元 3 个平行样，邻近质地构型调查点，不是在每个混合样点都布设。污染风险样仍由专业人员按风险源评估。

工具的状态仅表示程序能检查到的结构或空间候选条件。评价单元同质性、土地利用真实性、样品代表性、外业照片、检测结论、签章和 CMA 能力范围必须人工审核。未知坐标系绝不通过猜 EPSG 或默认经纬度继续处理。RTK 导入将预检和 ArcPy 输入固定为同一快照；因 ArcGIS 对文本分隔、编码与 `schema.ini` 字段规则有自己的解释机制，首版只接收无 BOM UTF-8 逗号 CSV，并拒绝对该源文件生效的 `schema.ini` 配置。其他编码、分号、TAB、竖线等记录请先另存为规范格式，再导入。

举证照片必须按指导书6.2.5、10.4(1)⑤逐类核对：评价单元东南西北全景至少4张、近景至少2张、现场工作照至少1张、剖面照或土钻断面照每分样点至少1张、混合样采集照每分样点至少1张、四分法工作照至少1张/单元、容重采样点照片每容重样点至少1张、侵入体及砾石照片每分样点至少1张。软件只列照片文件并标记待审核；各项目仍须核对照片内容和真实性。

遥感线索不能替代现场踏勘、RTK核验、土壤采样与实验室检测。优先使用同季节、空间配准一致且产品处理级别可比的影像。统计表有效覆盖率表示评价单元内存在有效输入像元的比例，不等同于无云覆盖率；影像图和采样点布置图仍需按广西 v1.1 版式要求人工编制/核对。

本首版未自动生成正式图件/评价报告，不判定地块权属、土壤等级或污染是否合格。图件成果和文字成果仍需按模板人工制作并校审。
